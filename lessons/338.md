# 修改 Agent 趣味函式：積木

## 步驟 1
程式已提供以下 ``||player:當收到聊天指令時||`` 指令：**carrot**、**chicken** 和 **snowball**。

```template
player.onChat("carrot", function () {
    agent.setItem(CARROTS, 64, 1)
    for (let index = 0; index < 3; index++) {
        for (let index = 0; index < 5; index++) {
            agent.till(FORWARD)
            agent.move(FORWARD, 1)
            agent.place(DOWN)
        }
        agent.move(BACK, 5)
        agent.move(RIGHT, 2)
    }
})
player.onChat("chicken", function () {
    for (let index = 0; index < 15; index++) {
        mobs.spawn(CHICKEN, pos(0, 0, 0))
    }
})
player.onChat("snowball", function () {
    for (let index = 0; index < 15; index++) {
        mobs.spawn(SNOWBALL_PROJECTILE_MOB, pos(0, 10, 0))
    }
})
```

## 步驟 2
將提供的 **carrot** ``||player:當收到聊天指令時||`` 指令重新命名為 **torches**。修改 ``||agent:設定方塊或物品||``，將物品設為 **Torch**（火把）、數量 **32**、物品欄第 **1** 格。

```blocks
player.onChat("torches", function () {
    agent.setItem(TORCHES, 32, 1)
})
```
