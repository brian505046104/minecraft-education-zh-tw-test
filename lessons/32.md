## 活動 1

### 規律

有些問題需要反覆執行同一組動作。**重複迴圈**可以簡化解法，不必將相同的程式重寫很多次。
``||loops:重複||`` 積木是**複合敘述積木**。一般敘述積木能放的位置，它也能放；而且內部還有空間，可以放入更多敘述積木。

#### ~ tutorialhint

``||loops:重複||`` 積木可以放進事件積木中，但它的內部也需要加入敘述積木。

```blocks
player.onChat("clean", function () {
    for (let index = 0; index < 4; index++) {
    	
    }
})
```

### 重複一段動作

從 ``||loops:迴圈||`` 類別拖出 ``||loops:重複||`` 積木，放進 ``||player:聊天指令||``，再將現有的 ``||agent:Agent 破壞方塊||`` 和 ``||agent:Agent 移動||`` 程式積木放進去。

``||loops:重複||`` 積木是一種**迴圈**，因為它會反覆執行同一段程式。

#### ~ tutorialhint

```blocks
player.onChat("clean", function () {
    for (let index = 0; index < 4; index++) {
        agent.destroy(FORWARD)
        agent.move(FORWARD, 1)
    }
})
```

### 迴圈次數

我們需要指定 ``||loops:重複||`` 積木執行的次數。預設是 4 次，但 Agent 有 12 格需要清理。因此，可以將 ``||loops:重複||`` 積木中的 **4** 改成 **12**。

#### ~ tutorialhint

```blocks
player.onChat("clean", function () {
    for (let index = 0; index < 12; index++) {
        agent.destroy(FORWARD)
        agent.move(FORWARD, 1)
    }
})
```

### 複習

重複迴圈會將一串敘述執行指定次數。迴圈能大幅減少解決問題時需要撰寫的程式量。
