# Agent 挖掘通道：Javascript


## 步驟 1
編寫 ``||player:收到聊天指令時||``，命名為 **"destroy"**。

```javascript
player.onChat("destroy", function () {
})
```

## 步驟 2
在 ``||player:收到聊天指令時 ||`` 裡加入 ``||loops:當條件成立時重複||``，只要 ``||agent: 偵測||`` 偵測到**前方**有方塊，就持續執行。 

```javascript
player.onChat("destroy", function () {
    while (agent.detect(AgentDetection.Block, FORWARD)) {  	
    }
})
```

## 步驟 3
在 ``||loops:當條件成立時重複||`` 裡，讓 Agent ``||agent:破壞||`` **前方**的方塊。

```javascript
player.onChat("destroy", function () {
    while (agent.detect(AgentDetection.Block, FORWARD)) {
        agent.destroy(FORWARD)
    }
})
```

## 步驟 4

在 ``||loops:當條件成立時重複||`` 裡的 ``||agent:破壞前方||`` 之後，讓 Agent ``||agent:向前移動||`` **一格**。

```javascript
player.onChat("destroy", function () {
    while (agent.detect(AgentDetection.Block, FORWARD)) {
        agent.destroy(FORWARD)
        agent.move(FORWARD, 1)
    }
})
```

## 步驟 5

在 ``||agent:向前移動||`` 之後，讓 Agent ``||agent:破壞||`` **上方**方塊，再**結束** ``||loops:當條件成立時重複||``。

```javascript
player.onChat("destroy", function () {
    while (agent.detect(AgentDetection.Block, FORWARD)) {
        agent.destroy(FORWARD)
        agent.move(FORWARD, 1)
        agent.destroy(UP)
    }
})
```
## 步驟 6

按下**播放**，回到 Minecraft，按 **t**，試用 **destroy**。 

```javascript
player.onChat("destroy", function () { 
    while (agent.detect(AgentDetection.Block, FORWARD)) { 
        agent.destroy(FORWARD) 
        agent.move(FORWARD, 1) 
        agent.destroy(UP) 
    } 
})
```
