
# 建造橋梁：積木程式


## 步驟 1
取出 ``||player:收到聊天指令時||`` 指令，命名為 **“build”**。

```blocks
player.onChat("build", function () {
})
```

## 步驟 2
取出 ``||agent:設定方塊||``，設定在第 **1** 格物品欄放入 **64** 個**橡木材**。把設定完成的 ``||agent:設定方塊||`` 拖進 ``||player:收到聊天指令時||`` 指令中。 

```blocks
player.onChat("build", function () {
    agent.setItem(PLANKS_OAK, 64, 1)
})
```

## 步驟 3
取出 ``||agent:Agent 移動||`` 積木，設為**向前**移動 **1** 格，再拖進 ``||player:收到聊天指令時||`` 指令中，接在 ``||agent:設定||`` 積木後面。

```blocks
player.onChat("build", function () {
    agent.setItem(PLANKS_OAK, 64, 1)
    agent.move(FORWARD, 1)
})
```

## 步驟 4

取出 ``||loops:當條件成立時重複||`` 迴圈，拖進 ``||player:收到聊天指令時||`` 指令中，接在 ``||agent:Agent 移動||`` **向前移動**的積木後面。取出 ``||logic:不成立||`` 積木，拖進 ``||loops:當條件成立時重複||`` 迴圈的 **true** 條件欄位。取出 ``||agent:Agent 偵測||`` 積木，設為偵測**方塊**與**下方**。把設定好的 ``||agent:Agent 偵測||`` 拖進 **not** 的括號中。

```blocks
player.onChat("build", function () {
    agent.setItem(PLANKS_OAK, 64, 1)
    agent.move(FORWARD, 1)
    while (!(agent.detect(AgentDetection.Block, DOWN))) {
    	
    }
})
```

## 步驟 5

取出 ``||agent:Agent 放置||`` 積木，設為**向下**放置，再拖進 ``||loops:當條件成立時重複||`` 迴圈中。

```blocks
player.onChat("build", function () {
    agent.setItem(PLANKS_OAK, 64, 1)
    agent.move(FORWARD, 1)
    while (!(agent.detect(AgentDetection.Block, DOWN))) {
        agent.place(DOWN)
    }
})
```

## 步驟 6

在現有 ``||agent:移動||`` **向前移動 1 格**的積木上按右鍵，將它複製。把新的 ``||agent:移動||`` **向前移動 1 格**積木拖進 ``||loops:當條件成立時重複||`` 迴圈中，接在 ``||agent:Agent 放置||`` 向下放置的積木後面。

```blocks
player.onChat("build", function () {
    agent.setItem(PLANKS_OAK, 64, 1)
    agent.move(FORWARD, 1)
    while (!(agent.detect(AgentDetection.Block, DOWN))) {
        agent.place(DOWN)
        agent.move(FORWARD, 1)
    }
})
```

## 步驟 7
按下**執行**按鈕，回到 Minecraft，按 **t**，試著輸入 **build**。

player.onChat("build", function () {

        agent.place(DOWN) 
        agent.move(FORWARD, 1) 
    } 
})
