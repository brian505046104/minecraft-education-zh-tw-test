## 步驟 1

建立一個 ``||player:收到聊天指令時||`` 指令，命名為「**position**」。

```javascript
player.onChat("position", function () {
    
})
```

## 步驟 2
建立變數 **PlayerPosition**，將它設為 ``||positions: 世界座標||`` 座標。 

```javascript
let PlayerPosition: Position = null 
player.onChat("position", function () { 
    PlayerPosition = player.position() 
}) 
```

## 步驟 3
在 ``||player:收到聊天指令時||`` 指令中，建立變數 **from_position**，將值設為 **PlayerPosition** 加上 (6,0,0)。
	
```javascript
let PlayerPosition: Position = null 
let from_position: Position = null 
player.onChat("position", function () { 
    PlayerPosition = player.position() 
    from_position = positions.add( 
    player.position(), 
    pos(6, 0, 0) 
    ) 
}) 
```

## 步驟 4
在 ``||player:收到聊天指令時||`` 指令中，建立變數 **to_position**，將值設為變數 **PlayerPosition** 加上 (-6,13,0)。 

```javascript
let PlayerPosition: Position = null
let from_position: Position = null
let to_position: Position = null
player.onChat("position", function () {
    PlayerPosition = player.position()
    from_position = positions.add(
    PlayerPosition,
    pos(6, 0, 0)
    )
    to_position = positions.add(
    PlayerPosition,
    pos(-6, 13, 0)
    )
})
```

## 步驟 6
在 **wall** 的 ``||player:收到聊天指令時||`` 指令中，加入 ``||blocks:填滿並取代||``，從變數 **from_position** 到變數 **to_position**，填入**玻璃**。

## 步驟 7
使用 ``||blocks: 方塊被破壞時||`` 建立事件：當**玻璃**方塊被打破時，在變數 **from_position** 到變數 **to_position** 的範圍內，取一個 ``||positions: 隨機位置||``，再用 ``||blocks:放置||`` 放置**鑽石**方塊。 

```javascript

    ))

```

## 步驟 8
使用 ``||blocks: 方塊被破壞時||`` 建立事件：當**鑽石**方塊被打破時，在變數 **from_position** 到變數 **to_position** 的範圍內，取一個 ``||positions: 隨機位置||``，再用 ``||blocks:放置||`` 放置**橘色羊毛**方塊。
