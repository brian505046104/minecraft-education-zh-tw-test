# 往高處蓋！

## 步驟 1
編寫程式，讓 Agent 使用**橡木**方塊，搭建一座 **10** 格高的塔。先使用 ``||agent:設定方塊或物品||`` 指令，確認 Agent 有 **64** 個**橡木材**。再使用 ``||agent:Agent 放置方塊||`` 積木，讓 Agent 往**前方**、**左側**及**右側**放置橡木材。放好方塊後，Agent 需要**向上移動**。  

#### ~ tutorialhint 
試著使用 ``||loops:重複||`` 積木，將次數改成 **10**。 

## 步驟 2
編寫程式，讓 Agent 從塔上**往下**移動，搭建 **10** 格高的**梯子**，讓你也能爬上去！

#### ~ tutorialhint 
別忘了使用 ``||agent: 設定 Agent 的方塊||``，在 Agent 物品欄選取 **64** 個**梯子**，Agent 才能放置梯子。 


```ghost
player.onChat("tower", function () {
    agent.move(FORWARD, 1)
    agent.setItem(LADDER, 64, 1)
    for (let index = 0; index < 10; index++) {
        agent.place(FORWARD)
        agent.move(UP, 1)
    }
    agent.move(DOWN, 10)
})
```
