## 第一個活動

### 依序執行

在 ``||player:收到聊天指令時||`` 中安排多個動作，就能讓 Agent 依序完成不同的事。Agent 有多種能力，可以透過下拉選單調整。

我們已經有一個名為 **interact** 的 ``||player:收到聊天指令時||``，裡面放了 ``||agent:Agent 移動||`` 積木，但還需要讓 Agent 操作控制桿。 

#### ~ tutorialhint

按**下一步**繼續教學。

### Agent 互動

``||agent:Agent||`` 類別中的 ``||agent:Agent 互動||`` 積木，能讓 Agent 操作控制桿、按鈕、門、柵欄門等機關。

從 ``||agent:Agent||`` 類別拖出 ``||agent:Agent 互動||`` 積木，放進 **interact** 的 ``||player:收到聊天指令時||`` 中，接在 ``||agent:Agent 移動||`` 積木下方。

#### ~ tutorialhint

```blocks
player.onChat("interact", function () {
    agent.move(FORWARD, 1)
    agent.interact(FORWARD)
})
```

### 複習

按下綠色執行按鈕，將新的聊天指令載入 Agent。在 Minecraft 聊天欄輸入 **interact**，執行 **interact** 的 ``||player:聊天指令||`` 程式。

#### ~ tutorialhint

```blocks
player.onChat("interact", function () {
    agent.move(FORWARD, 1)
    agent.interact(FORWARD)
})
```

```template
player.onChat("interact", function () {
    agent.move(FORWARD, 1)
})
```
