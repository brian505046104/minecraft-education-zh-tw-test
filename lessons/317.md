## 步驟 2


## 步驟 3
取出 ``||mobs:在指定位置生成動物||`` 積木，拖進 ``||loops:重複||`` 迴圈中。選擇**殭屍馬**，位置設為 (0,0,0)。

**注意：**這個動作會在迴圈中重複 6 次。

```blocks
player.onItemInteracted(BONE, function () { 
    for (let index = 0; index < 6; index++) { 
        mobs.spawn(ZOMBIE_HORSE, pos(0, 0, 0)) 
    } 
}) 
```

## 步驟 4
再取出一個 ``||loops:重複||`` 迴圈，拖進使用**石斧**的 ``||player: 使用物品時||`` 指令中，設為重複 **4** 次。

```blocks
player.onItemInteracted(BONE, function () { 
    for (let index = 0; index < 6; index++) { 
        mobs.spawn(ZOMBIE_HORSE, pos(0, 0, 0)) 
    } 
    for (let index = 0; index < 4; index++) { 
      
    } 
}) 
```

## 步驟 5
再取出一個 ``||mobs:在指定位置生成動物||`` 積木，拖進新的 ``||loops:重複||`` 迴圈中。選擇**骷髏馬**，位置設為 (0,0,0)。

**注意：**這個動作會在迴圈中重複 **4** 次。

```blocks
player.onItemInteracted(BONE, function () { 
    for (let index = 0; index < 6; index++) { 
        mobs.spawn(ZOMBIE_HORSE, pos(0, 0, 0)) 
    } 
    for (let index = 0; index < 4; index++) { 
        mobs.spawn(SKELETON_HORSE, pos(0, 0, 0)) 
    } 
}) 
```
