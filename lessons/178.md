## 步驟 1
我們已替你建立函式 **plantSeed**，內容就是前一個活動用過的程式。現在把 ``||player: 收到聊天指令時||`` 指令拖進工作區，命名為 **run**。加入 ``||loops: 重複||`` 迴圈，再點選**進階**區段中的**函式**，將 ``||function:呼叫 plantSeed||`` 函式拖進迴圈。數一數 Agent 需要重複執行 **plantSeed** 函式幾次。 

### ~ tutorialHint
函式位於**進階**區段中。替寫好的程式留下說明，也是很好的習慣，就像我們替函式留下的註解一樣。 

```template
/**
 * A function allows you to easily reuse code.
 */
function plantSeed () {
    agent.till(FORWARD)
    agent.move(FORWARD, 1)
    agent.place(DOWN)
}
```
