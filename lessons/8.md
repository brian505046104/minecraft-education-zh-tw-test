# 第 1 課：用程式建造道路網路

## 步驟 1
將 ``||Player:收到聊天指令時||`` 積木中的 **run** 改成 **road_1**。選取 ``||Blocks:填滿為||`` 積木，拖進 ``||Player:收到聊天指令時||`` 積木中。

### ~ tutorialhint
``` blocks
player.onChat("road_1", function () {
    blocks.fill(
    GRASS,

    pos(0, 0, 0),
    pos(0, 0, 0),
    FillOperation.Replace
    )
})
```

## 步驟 2
使用下拉選單，把方塊種類從 **草地（Grass）** 改為 **灰色混凝土（Gray Concrete）**。
### ~ tutorialhint

``` blocks
player.onChat("road_1", function () {
    blocks.fill(
    GRAY_CONCRETE,
    pos(0, 0, 0),
    pos(0, 0, 0),
    FillOperation.Replace
    )
})
```

## 步驟 3
打開 ``||Positions:座標||`` 工具箱，將世界座標 ``||Positions:[0] [0] [0]||`` 積木拖到程式工作區。
將世界座標 ``||Positions:[0] [0] [0]||`` 積木拖進 ``||Blocks:填滿||`` 積木，取代其中的 ``||Positions:相對座標||`` 座標積木。

### ~ tutorialhint
``` blocks
player.onChat("road_1", function () {
    blocks.fill(
    GRAY_CONCRETE,
    world(0, 0, 0),
    pos(0, 0, 0),
    FillOperation.Replace
    )
})
```

## 步驟 4
從 ``||Positions:座標||`` 工具箱再拖出一個 ``||Positions:世界座標 [0] [0] [0]||`` 座標積木，取代 ``||Blocks:填滿為||`` 積木中的第二個 ``||Positions:相對座標||`` 座標積木。

### ~ tutorialhint
``` blocks
player.onChat("road_1", function () {
    blocks.fill(
    GRAY_CONCRETE,
    world(0, 0, 0),
    world(0, 0, 0),
    FillOperation.Replace
    )
})
```

## 步驟 5
快要可以測試了！還有一個重要設定：將中間的 **Y** 座標減少 1。本例改成 **68**。現在測試程式，若設定正確，草地原來的位置就會出現道路。

### ~ tutorialhint
``` blocks
player.onChat("road_1", function () {
    blocks.fill(
    GRAY_CONCRETE,
    world(-21, 68, -565),
    world(61, 68, -569),
    FillOperation.Replace
    )
})

```

## 步驟 6
重複這些步驟，建造第二條道路。

### ~ tutorialhint
``` blocks
player.onChat("road_2", function () {
    blocks.fill(
    GRAY_CONCRETE,
    world(-21, 68, -532),
    world(61, 68, -536),
    FillOperation.Replace
    )
})
```
