## 步驟 1
修正這段程式。目標是：Agent 持續**檢查**是否有**空氣**方塊，在**沒有**找到時就**右移**。如果在**前方**找到**青金石**方塊，就**右移**、**左轉**，再**右移**。接著，讓 Agent 顯示「Found the break!」（找到斷裂處了！），並**向前放置紅石方塊**。



```template
player.onChat("repair", function () {
    while (agent.inspect(AgentInspection.Block, FORWARD) == AIR) {
        agent.move(RIGHT, 1)
        if (agent.inspect(AgentInspection.Block, FORWARD) == LAPIS_LAZULI_BLOCK) {
            agent.move(RIGHT, 1)
            agent.turn(RIGHT_TURN)
            agent.move(LEFT, 1)
        }
    }
    player.say("Found the break!")
    agent.setItem(GRASS, 1, 1)
    agent.place(FORWARD)
})
```
