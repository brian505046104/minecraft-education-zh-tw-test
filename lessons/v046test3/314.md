## 步驟 1
把 ``||player: 收到聊天指令時||`` 命名為 **tp**。把 ``||agent:傳送 Agent||`` 拖進 **tp** 的 ``||player: 收到聊天指令時||``。

```blocks
player.onChat("tp", function () {
    agent.teleportToPlayer()
})
```

## 步驟 3

再取出 ``||player:收到聊天指令時||``，命名為 **farm**。

```blocks
player.onChat("farm", function () { 
 
}) 
```

## 步驟 4
把 ``||agent:設定方塊或物品||`` 拖進 **farm** 的 ``||player:收到聊天指令時||``。選擇**胡蘿蔔**，數量設為 **64**，格數設為 **1**。

```blocks
player.onChat("farm", function () { 
    agent.setItem(CARROTS, 64, 1) 
}) 
```

## 步驟 5

```blocks
    agent.setItem(CARROTS, 64, 1)

    }

```

## 步驟 6
取出 ``||agent:Agent 移動||``，設為**向後 7 格**，拖進 ``||loops:重複||``。

```blocks
player.onChat("farm", function () { 
    agent.setItem(CARROTS, 64, 1) 
    for (let index = 0; index < 2; index++) { 
        agent.move(BACK, 7) 
    } 
}) 
```

## 步驟 7
再取出 ``||agent:Agent 移動||``，設為**向右 4 格**，拖進 ``||loops:重複||``，放在迴圈最下方。

```blocks
player.onChat("farm", function () { 
    agent.setItem(CARROTS, 64, 1) 
    for (let index = 0; index < 2; index++) { 
        agent.move(BACK, 7) 
        agent.move(RIGHT, 4) 
    } 
}) 
```

## 步驟 8
再取出 ``||loops:重複||``，設為重複 **7** 次，拖進原有的 ``||loops:重複||``，放在 ``||agent:移動||`` **向後 7 格**上方。

```blocks
player.onChat("farm", function () { 
    agent.setItem(CARROTS, 64, 1) 
    for (let index = 0; index < 2; index++) { 
        for (let index = 0; index < 7; index++) { 
          
        } 
        agent.move(BACK, 7) 
        agent.move(RIGHT, 4) 
    } 
}) 
```

## 步驟 9
新增 ``||agent:耕地||``，設為**前方**，拖進第二個、也就是內層的重複迴圈。  

```blocks
player.onChat("farm", function () { 
    agent.setItem(CARROTS, 64, 1) 
    for (let index = 0; index < 2; index++) { 
        for (let index = 0; index < 7; index++) { 
            agent.till(FORWARD) 
        } 
        agent.move(BACK, 7) 
        agent.move(RIGHT, 4) 
    } 
}) 
```

## 步驟 10
新增 ``||agent:移動||``，設為**向前 1 格**，拖進第二個、也就是內層的重複迴圈。

```blocks
player.onChat("farm", function () { 
    agent.setItem(CARROTS, 64, 1) 
    for (let index = 0; index < 2; index++) { 
        for (let index = 0; index < 7; index++) { 
            agent.till(FORWARD) 
            agent.move(FORWARD, 1) 
        } 
        agent.move(BACK, 7) 
        agent.move(RIGHT, 4) 
    } 
}) 
```

## 步驟 11
新增 ``||agent:放置||``，設為**向下**，拖進第二個、也就是內層的重複迴圈。

```blocks
player.onChat("farm", function () {
    agent.setItem(CARROTS, 64, 1)
    for (let index = 0; index < 2; index++) {
        for (let index = 0; index < 7; index++) {
            agent.till(FORWARD)
            agent.move(FORWARD, 1)
            agent.place(DOWN)
        }
        agent.move(BACK, 7)
        agent.move(RIGHT, 4)
    }
})
```
