# 用迴圈蓋房子：Javascript

## 步驟 1
編寫 ``||player:當收到聊天指令時||`` 指令，讓 Agent 執行 ``||agent:傳送到玩家身邊||``，並命名為 **tp**。 

```javascript
player.onChat("tp", function () { 
    agent.teleportToPlayer() 
}) 
```

## 步驟 2
再編寫一個 ``||player:當收到聊天指令時||`` 指令，命名為 **walls**。

```javascript
player.onChat("walls", function () { 
 
}) 
```

## 步驟 3
在 **walls** 的 ``||player: 當收到聊天指令時||`` 指令內編寫 ``||agent:設定方塊或物品||``，將物品設為**相思木材**、數量 **64**、物品欄第 **1** 格。

```javascript
player.onChat("walls", function () { 
    agent.setItem(PLANKS_ACACIA, 64, 1) 
}) 
```

## 步驟 4
在 **walls** 的 ``||player:當收到聊天指令時||`` 指令內，編寫重複 **3** 次的 ``||loops:for 迴圈||`` 迴圈，執行 ``||agent:移動||``，設定為**向上 1 格**。

```javascript
  player.onChat("walls", function () { 
    agent.setItem(PLANKS_ACACIA, 64, 1) 
    for (let index = 0; index < 3; index++) { 
        agent.move(UP, 1) 
    } 
}) 
```

## 步驟 5
在第一個 ``||loops:for 迴圈||`` 迴圈內、``||agent:移動||`` 程式下方，再編寫 ``||loops:for 迴圈||`` 迴圈，讓 ``||agent:Agent 右轉||`` 步驟重複 **4** 次。

```javascript
player.onChat("walls", function () { 
    agent.setItem(PLANKS_ACACIA, 64, 1) 
    for (let index = 0; index < 3; index++) { 
        agent.move(UP, 1) 
        for (let index = 0; index < 4; index++) { 
            agent.turn(RIGHT_TURN) 
        } 
    } 
}) 
```

## 步驟 6
在第二個 ``||loops:for 迴圈||`` 迴圈內、``||agent:右轉||`` 程式上方，編寫第三個 ``||loops:for 迴圈||`` 迴圈，重複 **4** 次向下執行 ``||agent:放置||``，以及向前 **1** 格的 ``||agent:移動||``。

```javascript
player.onChat("walls", function () { 
    agent.setItem(PLANKS_ACACIA, 64, 1) 
    for (let index = 0; index < 3; index++) { 
        agent.move(UP, 1) 
        for (let index = 0; index < 4; index++) { 
            for (let index = 0; index < 4; index++) { 
                agent.place(DOWN) 
                agent.move(FORWARD, 1) 
            } 
            agent.turn(RIGHT_TURN) 
        } 
    } 
}) 
```

## 步驟 7
編寫新的 ``||player:當收到聊天指令時||`` 指令，命名為 **roof**。   

```javascript
player.onChat("roof", function () { 
 
}) 
```

## 步驟 8
使用 ``||agent:設定方塊或物品||``，將物品設為**紅磚半磚**、數量 **64**、物品欄第 **1** 格，再讓 Agent 執行 ``||agent:移動||``，設定為**向上 1 格**。

```javascript
player.onChat("roof", function () { 
    agent.setItem(BRICKS_SLAB, 64, 1) 
    agent.move(UP, 1) 
}) 
```

## 步驟 9
在 **roof** 的 ``||player:當收到聊天指令時||`` 指令內，編寫 ``||loops:for 迴圈||`` 迴圈，重複 **4** 次執行 ``||agent:Agent 移動||``（**向後 4 格**）和 ``||agent:Agent 移動||``（**向右 1 格**）。  
	
```javascript
player.onChat("roof", function () { 
    agent.setItem(BRICKS_SLAB, 64, 1) 
    agent.move(UP, 1) 
    for (let index = 0; index < 4; index++) { 
        agent.move(BACK, 1) 
        agent.move(RIGHT, 1) 
    } 
}) 
```

## 步驟 10
在前一個 ``||loops:for 迴圈||`` 迴圈內、向**後**的 ``||agent:移動||`` 步驟上方，再編寫 ``||loops:for 迴圈||`` 迴圈，重複 **4** 次執行 ``||agent:向下放置||`` 和向前 **1** 格的 ``||agent:移動||``。

```javascript
player.onChat("roof", function () { 
    agent.setItem(BRICKS_SLAB, 64, 1) 
    agent.move(UP, 1) 
    for (let index = 0; index < 4; index++) { 
        for (let index = 0; index < 4; index++) { 
            agent.place(DOWN) 
            agent.move(FORWARD, 1) 
        } 
        agent.move(BACK, 1) 
        agent.move(RIGHT, 1) 
    } 
}) 
```
