## 步驟 2

首先要偵測鐵礦，可以先檢查 Agent 下方的方塊。
加入 ``||logic:如果就執行||``，在裡面放入 ``||logic:0 = 0||`` 積木。
在比較式左側放入 ``||agent: Agent 檢查下方方塊||``，偵測下方的方塊。
在比較積木右側，選擇鐵礦方塊。
在這個 if 陳述式中加入 ``||agent:Agent 破壞下方||``。
現在試著執行程式。任何時候都可以使用手機重設任務。   

```blocks
if (agent.inspect(AgentInspection.Block, DOWN) == IRON_ORE) {
            agent.destroy(DOWN)
        }
```

## 步驟 3

運用上一個練習寫好的程式，你也能檢查並挖掘其餘的礦壁嗎？
把這段程式放進 ``||loops:重複 3 次||`` 指令中，每次讓 Agent 向上移動 1 格。
別忘了再讓 Agent 回到下方。
現在試著執行程式。任何時候都可以使用手機重設任務。 

```blocks
    if (agent.inspect(AgentInspection.Block, DOWN) == IRON_ORE) {
        agent.destroy(DOWN)
    }
    for (let index = 0; index < 3; index++) {
        if (agent.inspect(AgentInspection.Block, LEFT) == IRON_ORE) {
            agent.destroy(LEFT)
        }
        agent.move(UP, 1)
    }
    agent.move(DOWN, 2)

```

## 步驟 4

最後，把整段程式再放進另一個 ``||loops:重複 X 次||`` 指令中。你需要數一數，Agent 總共要向前移動多少格。
最後這一部分就交給你了，祝你好運！
