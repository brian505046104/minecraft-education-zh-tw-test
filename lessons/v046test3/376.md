# 修復電路


## 步驟 1 @unplugged

![任務俯視圖](https://raw.githubusercontent.com/CausewayDigital/Minecraft-EE-MakeCode/main/tutorials/seymour-island/images/seymour_task_1_overhead.jpg)
這項任務需要修復紅石電路。下方綠色方塊標出了缺少零件的位置。
Agent 帶著足夠的紅石，隨時可以開始修復。
將程式放在 ``||loops: 當開始時||`` 區段中。準備好執行時，按下右下角的 **play（播放）** 按鈕。
按下 **Next（下一步）** 按鈕繼續。

## 步驟 2
首先，讓 Agent 到達以綠色標示的損壞區域。
試著使用 ``||agent:Agent 向前移動||`` 和 ``||agent:Agent 左轉／右轉||`` 指令，調整 Agent 的位置，
讓它位於其中一個綠色方塊的上方。

```template
//
```

```block
agent.move(FORWARD, 1)
agent.turn(LEFT_TURN)
agent.move(FORWARD, 2)

```


## 步驟 3
接著使用 ``||agent:Agent 向下放置方塊||``，在綠色方塊上放置紅石，修好這一段電路。
```blocks
agent.place(DOWN)
```


## 步驟 4
現在你已經知道做法了，請編寫程式，讓 Agent 在另外 2 個綠色方塊上放好紅石。
如果卡住，或想重新開始，可以使用手機重設任務。

```ghost
    agent.move(FORWARD, 1)
    agent.turn(RIGHT_TURN)
    agent.move(FORWARD, 1)
    agent.place(DOWN)
    agent.turn(LEFT_TURN)
    agent.move(FORWARD, 1)
    agent.turn(RIGHT_TURN)
    agent.move(FORWARD, 1)
    agent.place(DOWN)
    agent.turn(RIGHT_TURN)
    agent.turn(RIGHT_TURN)
    agent.move(FORWARD, 1)
    agent.place(DOWN)
```
