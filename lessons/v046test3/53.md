## 步驟 1

```blocks
})
```

## 步驟 2

取出 ``||player:玩家說出||``，輸入 **"Dig a cave"**（挖一個洞穴），拖進 ``||player:收到聊天指令時||``。

```blocks

    player.say("Dig a cave")
})
```

## 步驟 3

取出 ``||gameplay:設定時間||``，設為**白天**，拖進 ``||player:收到聊天指令時||`` **cave**，放在 ``||player:說出||`` 下方。

```blocks
player.onChat("cave", function () {
    player.say("Dig a cave")
    gameplay.timeSet(gameplay.time(DAY))
})
```

## 步驟 4

取出 ``||blocks:填入方塊||``，選擇**空氣**，設定位置：**從 -1.0,-1** 到 **1,2,1**，模式設為**取代**。

```blocks
player.onChat("cave", function () {
    player.say("Dig a cave")
    gameplay.timeSet(gameplay.time(DAY))
    blocks.fill(
    AIR,
    pos(-1, 0, -1),
    pos(1, 2, 1),
    FillOperation.Replace
    )
})
```

## 步驟 5

取出 ``||loops:重複||``，設為 **50** 次。把 ``||blocks:填入方塊||`` **空氣**拖進迴圈，再把整個 ``||loops:重複||`` 拖進 ``||player:收到聊天指令時||`` **cave**，放在 ``||gameplay:設定時間||`` **白天**下方。

```blocks
player.onChat("cave", function () {
    player.say("Dig a cave")
    gameplay.timeSet(gameplay.time(DAY))
    for (let index = 0; index < 50; index++) {
        blocks.fill(
        AIR,
        pos(-1, 0, -1),
        pos(1, 2, 1),
        FillOperation.Replace
        )
    }
})
```

## 步驟 6

取出 ``||variables:設定變數||``，建立名為 **bat_cave** 的變數。把 ``||player:玩家世界座標||`` 拖進 **bat_cave** 變數。
把完成的 ``||variables:設定變數||`` **bat_cave** 拖進 ``||player:收到聊天指令時||`` **cave**，放在 ``||loops:重複||`` **50** 次的迴圈下方。

```blocks
let batcave: Position = null
player.onChat("cave", function () {
    player.say("Dig a cave")
    gameplay.timeSet(gameplay.time(DAY))
    for (let index = 0; index < 50; index++) {
        blocks.fill(
        AIR,
        pos(-1, 0, -1),
        pos(1, 2, 1),
        FillOperation.Replace
        )
    }
    batcave = player.position()
})
```

取出 ``||player:說出||``，輸入「You have 10 seconds to go out before the bats arrive.」（蝙蝠到來前，你有十秒可以離開）。拖進 ``||player:收到聊天指令時||`` **cave**，放在 **bat_cave** 變數下方。

## 步驟 8

取出 ``||loops: 暫停||``，設為 **10** 秒（10,000 ms），拖到 ``||player:收到聊天指令時||`` 的末端。

## 步驟 10
