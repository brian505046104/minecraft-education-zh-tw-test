# 山貓圍欄：積木

## 步驟 1
建立 ``||player:收到聊天指令時||`` 指令，命名為 **fence**。

```blocks
player.onChat("fence", function () {
})
```

## 步驟 2

到工具箱的**進階**區找 ``||builder: 建造器||``。取出 ``||builder:傳送||``，拖進 ``||player: 收到聊天指令時||`` **fence** 指令。取出 ``||positions: 世界座標||``，把座標設為 **-695, 9, 880**。新增 ``||builder:面向||``，設為**西方（負 X）**，再拖進 ``||player:收到聊天指令時||`` **fence**，放在 ``||builder:傳送||`` 下方。

```blocks
player.onChat("1", function () {
    builder.teleportTo(positions.createWorld(-695, 9, 880)))
    builder.face(WEST)
})
```

## 步驟 3

取出 ``||builder:移動||``，設為**向前 21 格**。拖進 ``||player:收到聊天指令時||`` **fence**，放在 ``||builder:面向||`` **西方**下方。

```blocks
    builder.face(WEST)
    builder.move(FORWARD, 21)

})
```

## 步驟 4

新增 ``||builder:轉向||``，設為**右轉**。拖進 ``||player:收到聊天指令時|`` **fence**，放在向前移動的 ``||builder:移動||`` 下方。

```blocks
    builder.move(FORWARD, 21)
    builder.turn(RIGHT_TURN)
    
})
```

## 步驟 5

再取出 ``||builder:移動||``，設為**向前 9 格**，拖進 ``||player:收到聊天指令時||`` **fence**，放在 ``||builder:轉向||`` **右轉**下方。再新增 ``||builder:轉向||``，設為**右轉**。 

把 ``||builder: 轉向||`` 拖進 ``||player:收到聊天指令時||`` **fence**，放在 ``||builder:移動||`` **向前**下方。

```blocks
    builder.turn(RIGHT_TURN)
    builder.move(FORWARD, 9)
    builder.turn(RIGHT_TURN)
    })
```

## 步驟 6

再新增 ``||builder:建造器移動||``，設為**向前 21 格**；新增 ``||builder:建造器轉向||``，設為**右轉**；再取出 ``||builder:建造器移動||``，設為**向前 9 格**。把這些積木依序拖進 ``||player:收到聊天指令時||`` **fence**，放在最後一個 ``||builder:建造器轉向||`` **右轉**下方。

```blocks
    builder.turn(RIGHT_TURN)
    builder.move(FORWARD, 21)
    builder.turn(RIGHT_TURN)
    builder.move(FORWARD, 9)
})
```

## 步驟 7

要沿長方形周圍放置柵欄，新增 ``||builder:建造器沿標記路徑放置方塊||``，設為**橡木柵欄**。拖進 ``||player:收到聊天指令時||`` **fence**，放在最後一個 ``||builder:移動||`` **向前**下方。

```blocks
    builder.move(FORWARD, 9)
    builder.tracePath(OAK_FENCE)
})
```

## 步驟 8

完成柵欄後，取出 ``||mobs:生成動物||``，選擇**山貓**。加入 ``||math:隨機選取位置||``，設定柵欄內的座標範圍：從 **(-20, 4, -58)** 到 **(-37, 4, -50)**，再插入 ``||mobs:生成動物||`` **山貓**的位置欄。把**山貓**積木拖進 ``||player:收到聊天指令時||`` **fence**，放在 ``||builder:建造器沿標記路徑放置||`` **橡木柵欄**下方。

```blocks
    builder.tracePath(OAK_FENCE)
    mobs.spawn(OCELOT, randpos(
    world(-698, 9, 870),
    world(-715, 9, 880)
    ))
})
```

## 步驟 9

要在柵欄內生成第二隻山貓，複製整個 ``||mobs:生成動物||`` **山貓**積木。拖進 ``||player:收到聊天指令時||`` **fence**，放在原有**山貓**下方。

    mobs.spawn(OCELOT, randpos(
