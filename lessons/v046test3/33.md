## 第一個活動

### 做出判斷

有些問題需要反覆執行動作，但不是每個動作都要固定重複。``||logic:如果||`` 能判斷何時應執行某個動作，讓程式更簡潔。
``||logic:如果||`` 是另一種**複合陳述積木**，利用**條件**判斷是否執行其中的程式。條件為真時，就執行 ``||logic:如果||`` 內的程式。

#### ~ tutorialhint

**條件**可以為真或為假。**條件積木**有特別的尖角形狀，表示它能放進需要條件判斷的位置。

### Agent 偵測

試著搭配 ``||logic:如果||`` 和 ``||agent:Agent 偵測||``，讓 ``||agent:Agent 破壞||`` 只破壞實心方塊。
從 ``||logic:邏輯||`` 類別把 ``||logic:如果||`` 拖進 ``||loops:重複||``。
從 ``||agent:Agent||`` 類別把 ``||agent:Agent 偵測||`` 拖進 ``||logic:如果||`` 中形狀相符的位置。

#### ~ tutorialhint

```blocks
player.onChat("fix", function () {
    for (let index = 0; index < 12; index++) {
        if (agent.detect(AgentDetection.Block, FORWARD)) {
        }
    }
})
```
### 設定條件

依照 Agent 面向的方向，在 ``||agent:Agent 偵測||`` 的下拉選單中選擇檢查右側。``||agent:Agent 偵測||`` 能判斷 Agent 旁邊是否有實心方塊。
務必在 ``||agent:Agent 偵測||`` 選對方向。``||loops:重複||`` 已設定好正確的重複次數。

#### ~ tutorialhint

```blocks
player.onChat("fix", function () {
    for (let index = 0; index < 12; index++) {
        if (agent.detect(AgentDetection.Block, RIGHT)) {
           
        }
        
    }
})
```

### 如果條件成立……

如果 Agent 用 ``||agent:Agent 偵測||`` 偵測到右邊有方塊，就要用 ``||agent:Agent 破壞||`` 破壞它。在 ``||logic:如果||`` 裡加入 ``||agent:Agent 破壞||``，方向設為**右方**。
不管是否**偵測**到可破壞的方塊，完成後都要向前移動。因此在 ``||logic:如果||`` 後面加入 ``||agent:Agent 移動||`` **向前**。

#### ~ tutorialhint

```blocks
player.onChat("fix", function () {
    for (let index = 0; index < 12; index++) {
        if (agent.detect(AgentDetection.Block, RIGHT)) {
            agent.destroy(RIGHT)
        }
        agent.move(FORWARD, 1)
    }
})
```

### 執行程式

按下綠色的**播放**按鈕執行程式，再到聊天欄輸入 **fix**，讓 Agent 完成任務。

帶有條件判斷的程式能自行決定某段程式是否執行，不必再為每一步動作手動編寫指令。

#### ~ tutorialhint

```blocks
player.onChat("fix", function () {
    for (let index = 0; index < 12; index++) {
        if (agent.detect(AgentDetection.Block, RIGHT)) {
            agent.destroy(RIGHT)
        }
        agent.move(FORWARD, 1)
    }
})
```
