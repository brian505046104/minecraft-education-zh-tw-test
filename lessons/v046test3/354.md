# 移動 Agent：JavaScript

## 步驟 1
編寫 ``||player:當收到聊天指令時||`` 指令，命名為 **“tp”**。

```javascript
player.onChat("tp", function () {
})
```

## 步驟 2

在 **tp** 的 ``||player:當收到聊天指令時||`` 指令內，讓 Agent 執行 ``||agent:傳送到玩家身邊||``。

```javascript
player.onChat("tp", function () {
    agent.teleportToPlayer()
})
```

## 步驟 3

再編寫一個 ``||player:當收到聊天指令時||`` 指令，命名為 **“fd”**。

```javascript
player.onChat("fd", function () {
})
```

## 步驟 4

在 ``||player:當收到聊天指令時||`` 的 **fd** 指令內，讓 Agent 執行 ``||agent:移動||``，設定為**向前移動 5 格**。 

```javascript
player.onChat("fd", function () {
    agent.move(FORWARD, 5)
})
```

## 步驟 5

再編寫一個 ``||player:當收到聊天指令時||`` 指令，命名為 **“lt”**。

```javascript
player.onChat("lt", function () {
})
```

## 步驟 6

在 ``||player:當收到聊天指令時||`` 的 **lt** 指令內，讓 Agent 執行 ``||agent:轉向||``，設定為**左轉**。

```javascript
player.onChat("lt", function () {
    agent.turn(LEFT_TURN)
})
```

## 步驟 7

再建立一個 ``||player:當收到聊天指令時||`` 指令，命名為 **“rt”**。

```javascript
player.onChat("rt", function () {
    agent.turn(RIGHT_TURN)
})
```

## 步驟 8

在 **rt** 聊天指令內，讓 ``||agent:Agent||`` **右轉**。

```javascript
player.onChat("rt", function () {
    agent.turn(RIGHT_TURN)
})
```

## 步驟 9

按下 **Play（播放）** 按鈕，回到 Minecraft，按 **t** 開啟聊天室。一次輸入一個指令，依序測試 **tp**、**rt**、**lt**、**fd**，看看會發生什麼事。

```javascript
player.onChat("lt", function () {
    agent.turn(LEFT_TURN)
})
player.onChat("fd", function () {
    agent.move(FORWARD, 5)
})
player.onChat("tp", function () {
    agent.teleportToPlayer()
player.onChat("rt", function () { 
    agent.turn(RIGHT_TURN) 

})
```
