}

## 步驟 2
在 **walls** 函式內，讓 Agent 執行 ``||agent:設定方塊或物品||``，設定物品為**相思木材**、數量 **64**、物品欄第 **1** 格。

## 步驟 3
在 **walls** 函式內，編寫重複 **3** 次的 ``||loops:for 迴圈||`` 迴圈，執行 ``||agent:Agent 移動||``，設定為**向上 1 格**。

```javascript
function walls () {
    agent.setItem(PLANKS_ACACIA, 64, 1)
    for (let index = 0; index < 3; index++) {
        agent.move(UP, 1)
    }
}
```

## 步驟 4
再編寫一個重複 **4** 次的 ``||loops:for 迴圈||`` 迴圈，拖進第一個 ``||loops:for 迴圈||`` 迴圈，放在第一個 ``||agent:Agent 移動||`` 下方。在第二個迴圈中編寫 ``||agent:Agent 右轉||``。

```javascript
function walls () {
    agent.setItem(PLANKS_ACACIA, 64, 1) 
    for (let index = 0; index < 3; index++) { 
        agent.move(UP, 1) 
        for (let index = 0; index < 4; index++) { 
            agent.turn(RIGHT_TURN) 
        } 
    } 
}) 
```

## 步驟 5
編寫第三個 ``||loops:for 迴圈||`` 迴圈，拖進第二個 ``||loops:for 迴圈||`` 迴圈，放在 ``||agent: 右轉||`` 上方。將第三個 ``||loops:for 迴圈||`` 迴圈設定為重複 **4** 次。在最內層的 ``||loops:for 迴圈||`` 迴圈中，讓 Agent 執行 ``||agent:放置||``，設定為**向下**。新增 Agent 的 ``||agent:移動||``，設定為**向前 1 格**，放進最內層 ``||loops:for 迴圈||`` 迴圈，放在向下的 ``||agent:放置||`` 下方。

```javascript
function walls () {
    agent.setItem(PLANKS_ACACIA, 64, 1) 
    for (let index = 0; index < 3; index++) { 
        agent.move(UP, 1) 
        for (let index = 0; index < 4; index++) { 
            for (let index = 0; index < 4; index++) { 
                agent.place(DOWN) 
                agent.move(FORWARD, 1) 
            } 
            agent.turn(RIGHT_TURN) 
        } 
    } 
}) 
```

## 步驟 7
讓 Agent 執行 ``||agent:設定方塊或物品||``，設定為**紅磚半磚**、數量 **64**、物品欄第 **1** 格，拖進 **roof** 的 ``||functions:函式||``。另外，讓 Agent 執行 ``||agent:移動||``，設定為**向上 1 格**。

## 步驟 8
在 **roof** 的 ``||functions:函式||`` 內，編寫 ``||loops:for 迴圈||`` 迴圈，設定為重複 **4** 次。迴圈內先讓 Agent 執行 ``||agent:移動||``，設定為**向後 4 格**，再執行 ``||agent:移動||``，設定為**向右 1 格**。
	
```javascript
function roof () {
    agent.setItem(BRICKS_SLAB, 64, 1) 
    agent.move(UP, 1) 
    for (let index = 0; index < 4; index++) { 
        agent.move(BACK, 4) 
        agent.move(RIGHT, 1) 
    } 
}) 
```

## 步驟 9
