## 第一個活動

### 條件迴圈

有些需要迴圈的問題，使用 ``||loops:重複積木||`` 並不合適。我們可能需要持續執行程式，直到符合某個條件。

``||loops:當條件成立時重複||`` 是另一種迴圈積木，會根據條件決定是否重複執行裡面的程式。

#### ~ tutorialhint

只要條件為真，``||loops:當條件成立時重複||`` 積木就會執行裡面的程式。每次執行後，``||loops:當條件成立時重複||`` 會再次檢查條件，決定要不要再執行一次。當條件為假時，``||loops:當條件成立時重複||`` 迴圈就會結束。

### Agent 檢查

``||agent:Agent 檢查||`` 是一個值積木。**值積木**有明顯的圓弧外形，能提供一項資訊，也就是一個**值**。``||agent:Agent 檢查||`` 回傳的資訊，是 Agent 旁邊的 Minecraft 方塊種類。值積木可以放進其他積木需要填入數值或資訊的圓弧欄位。注意，``||agent:Agent 檢查||`` 就放在 ``||agent:設定 Agent 方塊或物品||`` 積木的圓弧欄位中。

#### ~ tutorialhint

把 ``||agent:Agent 檢查||`` 放進 ``||agent:設定 Agent 方塊或物品||``，就能將 Agent 右側的方塊種類放進 Agent 的物品欄。

### 比較值

``||logic:邏輯||`` 類別提供條件積木，可以用 ``||logic:比較||`` 比較兩個值。選擇**等號 (=)** 後，兩個值相同時，``||logic:比較||`` 就會回傳真。
試著用 ``||logic:比較||`` 建立 ``||loops:當條件成立時重複||`` 的條件：當 Agent 用 ``||agent:Agent 檢查||`` 檢查到**下方**是**鵝卵石**時，就繼續執行 ``||loops:當條件成立時重複||`` 裡的任務。

#### ~ tutorialhint

```blocks
player.onChat("copy", function () {
    while (agent.inspect(AgentInspection.Block, DOWN) == COBBLESTONE) {
        agent.setItem(agent.inspect(AgentInspection.Block, RIGHT), 1, 1)
        agent.place(LEFT)
        agent.move(FORWARD, 1)
    }
})
```

### 複習

``||loops:當條件成立時重複||`` 積木根據條件，決定是否繼續重複執行裡面的程式。當重複次數不確定、但重複條件很明確時，``||loops:當條件成立時重複||`` 迴圈就很實用。``||logic:比較||`` 積木能比較兩個值，建立條件。
