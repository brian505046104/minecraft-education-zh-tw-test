# 建造

## 步驟 1
使用 ``||mobs:給予||``，給自己至少 **34 個綠寶石**方塊。建立新的 ``||變數||``，命名為 **count**。取得 ``||blocks:當放置方塊時||`` 積木，設定為 **emerald**（綠寶石）。將 ``||變更 count||`` 積木拖進 ``||blocks: 當放置方塊時||``，再加入 ``||player: 說出||`` 積木，並將 ``||count||`` 放進 ``||player: 說出||`` 積木。這樣每次放置方塊時，遊戲就會計算你放了多少個。 

### ~ tutorialhint 

可以選擇鐵、黃金、綠寶石或鑽石。 

```blocks
let count = 0
blocks.onBlockPlaced(EMERALD_BLOCK, function () {
    count += 1
    player.say(count)
})

```
