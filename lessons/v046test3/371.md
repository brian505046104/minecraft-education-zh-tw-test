# 1. 修理

## 修理 @unplugged

現在有了修補用的木材，將 Agent 移到需要修理的區域。      
![Agent 修理船身](https://raw.githubusercontent.com/CausewayDigital/Minecraft-EE-MakeCode/main/tutorials/seymour-island/images/seymour_task_0_place_move.gif)

## 移動
首先，將 Agent 移到遠處的綠寶石方塊，也就是綠色方塊上方。   
接著按下一步。      

```blocks
agent.move(LEFT, 3)

```

## 修理 @unplugged
Agent 到達正確位置後，放置木材方塊，修補船身。
![Agent 修理船身](https://raw.githubusercontent.com/CausewayDigital/Minecraft-EE-MakeCode/main/tutorials/seymour-island/images/seymour_task_0_place.gif)

## 修理
接著使用 ``||Agent:Agent 向左放置方塊||`` 指令，放下剛才收集的木材方塊，
修補船身。

```blocks

agent.move(LEFT, 3)
agent.place(LEFT)


```
