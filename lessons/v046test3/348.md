# 山貓圍欄：JavaScript

## 步驟 1
編寫 ``||player:收到聊天指令時||``，命名為 **fence**。

```javascript
player.onChat("fence", function () {
})
```

## 步驟 2

使用 ``||builder:傳送建造器||``，傳送到世界座標 **-695, 9, 880**，面向**西方**。

```javascript
player.onChat("1", function () {
    builder.teleportTo(positions.createWorld(-18, 4, -50))
    builder.face(WEST)
})
```

## 步驟 3

讓建造器使用 ``||builder:移動||``，**向前 21 格**。 

```javascript
    builder.face(WEST) 
    builder.move(FORWARD, 21) 
}) 
```

## 步驟 4

讓建造器使用 ``||builder:轉向||``，向**右**轉。

```javascript
    builder.move(FORWARD, 21)
    builder.turn(RIGHT_TURN)
    
})
```

## 步驟 5

讓建造器 ``||builder:移動||`` **向前 9 格**，再 ``||builder:轉向||`` **右轉**。 

```javascript
    builder.turn(RIGHT_TURN)
    builder.move(FORWARD, 9)
    builder.turn(RIGHT_TURN)
    })
```

## 步驟 6

讓建造器 ``||builder:移動||`` **向前 21 格**、``||builder:轉向||`` **右轉**，再 ``||builder:移動||`` **向前 9 格**。

```javascript
    builder.turn(RIGHT_TURN)
    builder.move(FORWARD, 21)
    builder.turn(RIGHT_TURN)
    builder.move(FORWARD, 9)
})
```

## 步驟 7

要沿長方形周圍放上柵欄，讓建造器使用 ``||builder:沿路徑放置||``，沿原路徑建造**橡木柵欄**。

```javascript
    builder.move(FORWARD, 9)
    builder.tracePath(OAK_FENCE)
})
```

## 步驟 8

在剛建好的柵欄內，隨機用 ``||mobs:生成||`` 生成一隻**山貓**。

```javascript
    builder.tracePath(OAK_FENCE)
    mobs.spawn(OCELOT, randpos(
    world(-698, 9, 870),
    world(-715, 9, 880)
    ))
})
```

## 步驟 9

在剛建好的柵欄內，再隨機用 ``||mobs:生成||`` 生成另一隻**山貓**。

```javascript
    mobs.spawn(OCELOT, randpos(
```
