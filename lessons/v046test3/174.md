# 挖掘資源！

## 步驟 1
Agent 需要挖掘**金礦石**和**鐵礦石**方塊。試著建立幾個 ``||player:當收到聊天指令時||`` 指令，讓 Agent 朝不同方向移動，例如 **forward**、**back**、**right**。不用直接指定距離，可以改用變數。在遊戲聊天室輸入指令時，輸入 **forward** 和**一個數字**，例如 **forward 5**，就能讓 Agent **向前移動 5 步**。這樣一來，不必修改程式，也能隨時改變 Agent 移動的步數。
