# 第 3 課：用程式建造整排房屋

## 建築區 @unplugged
我們要在機構大樓前方的建築區蓋一棟房子。下圖是參考範例，你也可以自由設計！

![建築區圖片](https://raw.githubusercontent.com/Mojang/EducationContent/master/computing/unit-2/build_area.png)

## 步驟 1
依照自己的設計，手動蓋一棟房子。請在黃黑羊毛標示的指定建築區內建造。

按左側的返回箭頭，可以再次查看建築範例與建築區位置。

## 步驟 2
將 ``||Player:收到聊天指令時||`` 積木中的 **run** 改成 **clone_here**，再把 ``||Blocks:複製自||`` 積木拖進 ``||Player:收到聊天指令時||`` 積木中。

這個積木可以複製 Minecraft 世界中指定的區域，再放到另一個地方，就像其他軟體的複製與貼上。

複製後，建築的朝向會和原本相同。例如原本朝東，複製出來也會朝東。

#### ~ tutorialhint
``` blocks
player.onChat("clone_here.", function () {
    blocks.clone(
    pos(0, 0, 0),
    pos(0, 0, 0),
    pos(0, 0, 0),
    CloneMask.Replace,
    CloneMode.Normal
    )
})
```

## 步驟 3
前兩組座標界定一個立體範圍：``||Blocks:複製自||`` 座標是一個角，``||Blocks:終點||`` 座標是對角，兩者之間的所有方塊都會被選取，就像圖中的箱子。

第三組 ``||Blocks:貼上位置||`` 座標，代表要把複製的建築貼到哪裡。

試試看！找出房屋模型底部的一個角，圖中用黃色羊毛標示。

再找出上方的對角，讓這兩個角形成一個包住整棟建築的隱形箱子。圖中也用 **黃色羊毛（Yellow Wool）** 標示。

## 步驟 4
打開 ``||Positions:座標||`` 工具箱，把前兩組座標改為 ``||Positions:世界座標||`` 座標。由 **黃色羊毛** 標記取得的座標，都是絕對座標。

#### ~ tutorialhint
``` blocks
player.onChat("clone_here.", function () {
    blocks.clone(
    world(0, 0, 0),
    world(0, 0, 0),
    pos(0, 0, 0),
    CloneMask.Replace,
    CloneMode.Normal
    )
})
```

## 步驟 5
把第一組座標填入積木的 ``||Blocks:複製自||``，第二組填入下方的 ``||Blocks:終點||``。請注意，下圖的座標只是範例。

最後一組座標是相對於玩家的位置，所以玩家就是房屋貼上位置的標記。每次要複製另一棟房子，都需要移動玩家。

#### ~ tutorialhint
``` blocks
player.onChat("clone_here.", function () {
    blocks.clone(
    world(67, 69, -544),
    world(73, 77, -551),
    pos(0, 0, 0),
    CloneMask.Replace,
    CloneMode.Normal
    )
})
```


## 步驟 6
測試程式。在 Minecraft 中，先飛到空中測試，觀察建築會被複製到哪個位置。

## 步驟 7
開始建造一整排房屋！站在第一棟房子的預定位置，輸入 **clone_here**，就會看到房子出現。

完成城市中的整排房屋後，就可以移除原來的房屋模型。
