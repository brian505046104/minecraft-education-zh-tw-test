## 步驟 3
打開左側選單中的新工具箱：``||Math:數學||``。

這個工具箱的積木，能讓你在程式中使用數學運算。

將 ``||Math:隨機取數 [0] 到 [10]||`` 積木拖進 ``||Player:收到聊天指令時||`` 程式組，取代 ``||Agent:Agent 設定使用的物品欄||`` 積木中的數字。

這會讓 Agent 隨機選取物品欄中的一格，而不是固定選取某一格。

#### ~ tutorialhint
``` blocks

    for (let index = 0; index < 20; index++) {
        agent.setSlot(Math.randomRange(0, 10))
    }
})
```

## 步驟 10
回到 ``||Agent:Agent||`` 工具箱，把兩個 ``||Agent:Agent 放置 [前方]||`` 積木拖到工作區，第二個的方向設為 **後（back）**。

最後加入 ``||Agent:Agent 移動 [左]||`` 積木，完成程式。

#### ~ tutorialhint
``` blocks
player.onChat(" plant_flowers", function () {
    for (let index = 0; index < 20; index++) {
        agent.setSlot(Math.randomRange(1, 5))
        agent.move(FORWARD, Math.randomRange(0, 20))
        agent.place(FORWARD)
        agent.place(BACK)
        agent.setSlot(Math.randomRange(1, 5))
        agent.move(BACK, Math.randomRange(0, 20))
        agent.place(FORWARD)
        agent.place(BACK)
        agent.move(LEFT, 1)
    }
})
```
