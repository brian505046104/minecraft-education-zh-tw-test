# 文字列印：積木程式

## 步驟 1
建立一個 ``||player:收到聊天指令時||`` 指令，命名為 **mix**。在裡面放入名為 **starting_world_position** 的 ``||variables: 新增變數||``，將這個 ``||variable:變數||`` 設為 ``||player:玩家世界座標||``。

```blocks
player.onChat("mix", function () {
    starting_world_position = player.position()
})
```

## 步驟 2

加入 ``||blocks:印出文字||`` 程式，在位置 **(0,0,0)** 朝**西方**，以 ``||blocks:草地||`` 方塊印出變數 **word1**。

```blocks
player.onChat("mix", function () {
    starting_world_position = player.position()
    blocks.print(
    word1,
    GRASS,
    pos(0, 0, 0),
    WEST
    )
})
```

## 步驟 3

加入 ``||loops:開始時||``，在裡面放入新變數 **word1**，將值設為 **"rail"**。將變數 **starting_world_position** 設為 **(0,0,0)**。

## 步驟 4

建立一個 ``||player:收到聊天指令時||`` 指令，命名為 **mix2**。再加入一個 ``||variables: 變數||``，選擇 **starting_world_position**，將值設為 ``||player:玩家世界座標||``，再拖進 ``||player:收到聊天指令時||`` **mix2** 指令中。在這個 ``||player:收到聊天指令時||`` 指令裡加入 ``||blocks:印出文字||`` 積木，在位置 **(0,0,0)** 朝**西方**，以**平滑砂岩**印出變數 **word1**。把 **word1** 拖到 **starting_world_position** 變數正下方。

```blocks
player.onChat("mix2", function () {
    blocks.print(
    word1,
    SMOOTH_SANDSTONE,
    pos(0, 0, 0),
    WEST
    )
    starting_world_position = player.position()
})
```

## 步驟 5

## 步驟 6

## 步驟 7

再加入一個 ``||blocks:印出文字||`` 指令，放入 ``||text:合併文字||`` 積木，分別指定 **word1** 和 **word2**。將 ``||blocks:印出文字||`` 設為在位置 **(0,0,0)** 朝**西方**，使用**青金石**。把整個 ``||blocks:印出文字|`` 拖進 ``||player:收到聊天指令時||`` **mix2** 指令中，緊接在 **word2** 變數下方。 

```blocks
player.onChat("mix2", function () {
    blocks.print(
    word1,
    SMOOTH_SANDSTONE,
    pos(0, 0, 0),
    WEST
    )
    blocks.print(
    word2,
    PURPLE_WOOL,
    pos(0, 0, 0),
    WEST
    )
    blocks.print(
    "" + word1 + word2,
    LAPIS_LAZULI_BLOCK,
    pos(0, 0, 0),
    WEST
    )
    starting_world_position = player.position()
})
```

## 步驟 8

取出 ``||player:玩家行走時||`` 積木，設為 **fly**（飛行）。建立名為 **alphabet** 的新變數，將字串 **"ABCDEFGHIJKLMNOPQ"** 指定給它。把這個變數拖進 ``||player:玩家飛行時||`` 積木中。

```blocks
player.onTravelled(FLY, function () {
    alphabet = "ABCDEFGHIJKLMNOPQ"
})
```

## 步驟 9

再加入一個 ``||variables: 變數||``，命名為 **RandomLetter**。取出 ``||math:隨機取數||`` 積木，將範圍設為 **0** 到 **12**，再把整個 ``||math:隨機取數||`` 積木放進 **RandomLetter** 變數中。


```blocks
player.onTravelled(FLY, function () {
    alphabet = "ABCDEFGHIJKLMNOPQ"
    RandomLetter = Math.randomRange(0, 12)
    blocks.print(
    alphabet.charAt(RandomLetter),
    PUMPKIN,
    pos(-5, 2, 0),
    WEST
    )
})
```
