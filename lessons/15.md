# 第 3 課：用程式建造動物生活區

## 步驟 1
先告訴建築器從哪裡開始。在 MakeCode 中，將 ``||Player:收到聊天指令時||`` 積木中的 **run** 改為 **ocelot_wall**。

打開畫面左側的 ``||Advanced:進階||``，再打開 ``||Builder:建築器||`` 工具箱。``||Builder:建築器||`` 能操作 Minecraft 的位置機制，你可以把 ``||Builder:建築器||`` 想成看不見的 ``||Agent:Agent||``。

設定起點座標：把 ``||Builder:建築器傳送到 [~0] [~0] [~0]||`` 積木拖進 ``||Player:收到聊天指令時||`` 積木中。

#### ~ tutorialhint
``` blocks
player.onChat("ocelot_wall", function () {
    builder.teleportTo(pos(0, 0, 0))
})
```

## 步驟 2
把 ``||Positions:世界座標 [0] [0] [0]||`` 橢圓形積木拖到工作區，取代原本的 **相對（relative）** 座標。

將 ``||Positions:世界座標 [0] [0] [0]||`` 設為牆壁的起點。本例以 **金方塊（Gold Block）** 標記 **-40, 69, -575**。請把你自己的起點，也就是第一個標記的座標，記在學習手冊中。

#### ~ tutorialhint
``` blocks
player.onChat("ocelot_wall", function () {
    builder.teleportTo(world(-40, 69, -575))
})
```

## 步驟 3
接著告訴建築器要朝哪個方向蓋。Minecraft 有南北、東西和上下方向；原教材以指南針協助判斷。

你可以在物品欄裡找到指南針。

移動時，**指南針（compass）** 的指針也會轉動。原教材用它判斷北（紅色指針所指方向）、東、南、西；本例選擇西方，讓 ``||Builder:建築器||`` 朝這個方向工作。

## 步驟 4
回到 ``||Builder:建築器||`` 工具箱，找出 ``||Builder:建築器面向 [西（X 負方向）||`` 積木，加入主程式，用下拉選單選取建築所需的方向。

注意：如果你要朝東、北或南建造，就要對應調整積木。先判斷希望 ``||Builder:建築器||`` 前進的方向，再把方向填進積木中；原教材以 **指南針（compass）** 說明。

#### ~ tutorialhint
``` blocks
player.onChat("ocelot_wall", function () {
    builder.teleportTo(world(-40, 69, -575))
    builder.face(WEST)
})
```

## 步驟 5
回到 ``||Builder:建築器||`` 工具箱，把 ``||Builder:建築器移動 [前方]||`` 積木拖進主程式。

#### ~ tutorialhint
``` blocks
player.onChat("ocelot_wall", function () {
    builder.teleportTo(world(-40, 69, -575))
    builder.face(WEST)
    builder.move(FORWARD, 1)
})
```

## 步驟 6
把 ``||Builder:建築器移動 [前方]||`` 的數字改成預定建造的長度。本例是 **21** 格，你的圍欄可能不同。

接著把 ``||Builder:建築器轉向 [左]||`` 積木拖進主程式。

#### ~ tutorialhint
``` blocks
player.onChat("ocelot_wall", function () {
    builder.teleportTo(world(-40, 69, -575))
    builder.face(WEST)
    builder.move(FORWARD, 21)
    builder.turn(LEFT_TURN)
})
```

## 步驟 7
把方向改成 ``||Builder:建築器||`` 接下來要面對的方向。本例這一步寫的是右轉。

再加入 ``||Builder:建築器移動 [前方]||`` 積木，把數字改成新方向的長度；本例為 **9** 格。

#### ~ tutorialhint
``` blocks
player.onChat("ocelot_wall", function () {
    builder.teleportTo(world(-40, 69, -575))
    builder.face(WEST)
    builder.move(FORWARD, 21)
    builder.turn(RIGHT_TURN)
    builder.move(FORWARD, 9)
})
```

## 步驟 8
最後指定建材。回到 ``||Builder:建築器||`` 工具箱，把 ``||Builder:建築器從標記沿路徑鋪設||`` 積木拖進主程式，讓 ``||Builder:建築器||`` 有材料可以建造。

這個積木會沿著建築器走過的路徑，鋪上指定材料。

#### ~ tutorialhint
``` blocks
player.onChat("ocelot_wall", function () {
    builder.teleportTo(world(-40, 69, -575))
    builder.face(WEST)
    builder.move(FORWARD, 21)
    builder.turn(RIGHT_TURN)
    builder.move(FORWARD, 9)
    builder.tracePath(GRASS)
})
```

## 步驟 9
使用下拉選單，選取圍牆材料；本例使用 **石磚（Stone Bricks）**。

#### ~ tutorialhint
``` blocks
player.onChat("ocelot_wall", function () {
    builder.teleportTo(world(-40, 69, -575))
    builder.face(WEST)
    builder.move(FORWARD, 21)
    builder.turn(RIGHT_TURN)
    builder.move(FORWARD, 9)
    builder.tracePath(STONE_BRICKS)
})
```

## 步驟 10
執行程式建造牆壁。測試時，``||Builder:建築器||`` 應從 **-40, 69, -575** 出發，向西走 **21** 格，再 **左轉（left）** 走 **9** 格，沿路放置 **石磚（Stone Bricks）**，形成山貓區的小圍牆。與之前的 ``||Agent:Agent||`` 和 ``||Blocks:方塊||`` 相比，速度快很多。事先規劃好，就能在短時間內建造大型結構。

## 步驟 11
接著加上柵欄和細節。這道矮牆還擋不住山貓，要在上方加柵欄，避免牠們逃走。

## 步驟 12
重複上述程式，或調整現有程式。只需把高度提高一格，材料改為 **橡木柵欄（Oak Fence）**。參考下列範例：

#### ~ tutorialhint
``` blocks
player.onChat("ocelot_wall", function () {
    builder.teleportTo(world(-40, 69, -575))
    builder.face(WEST)
    builder.move(FORWARD, 21)
    builder.turn(RIGHT_TURN)
    builder.move(FORWARD, 9)
    builder.tracePath(OAK_FENCE)
})
```

## 步驟 13
現在可以替山貓的生活區增加一些設施。

接著編寫程式，將山貓放進牠的新家。

## 步驟 14
新增 ``||Player:收到聊天指令時||`` 積木到工作區，命名為 **ocelot**。

## 步驟 15
從 ``||Mobs:生物||`` 工具箱，把 ``||Mobs:在指定位置生成 [動物]||`` 積木拖進新的 ``||Player:收到聊天指令時||`` 程式組。

使用下拉選單，把 **動物（animal）** 改為 **山貓（ocelot）**。

#### ~ tutorialhint
``` blocks
player.onChat("ocelot", function () {
    mobs.spawn(OCELOT, pos(0, 0, 0))
})
```

## 步驟 16
打開 ``||Positions:座標||`` 工具箱，用 ``||Positions:世界座標 [0] [0] [0]||`` 取代 **相對（relative）** 座標。數字設為圍欄內的位置；本例為 **-50, 69, -580**。

#### ~ tutorialhint
``` blocks
player.onChat("ocelot", function () {
    mobs.spawn(OCELOT, world(-50, 69, -580))
})
```

## 步驟 17
執行程式生成山貓。完成後，你應該會看到一隻 **山貓（ocelot）**！
