# Agent 迷宮：JavaScript

## 步驟 1
建立一個 ``||player:收到聊天指令時||`` 指令，命名為 **tp**，讓 Agent 執行 ``||agent:傳送到玩家||``。

```javascript
player.onChat("tp", function () {
})
```

## 步驟 2

再建立一個 ``||player:收到聊天指令時||`` 指令，命名為 **side1**。讓 Agent 執行 ``||agent:移動時放置方塊||``，設為 **true**。加入 ``||agent:設定 Agent 物品||`` 指令，將數量設為 **64**。

```javascript
player.onChat("side1", function () { 
    agent.setAssist(PLACE_ON_MOVE, true)
    agent.setItem(GRASS, 64, 1) 
   
}) 
```

## 步驟 3

讓 Agent 用 ``||agent:向前移動||`` 向前移動 **4** 格，然後**左轉**。  

```javascript
player.onChat("side1", function () { 
    agent.setAssist(PLACE_ON_MOVE, true) 
    agent.move(FORWARD, 4) 
    agent.turn(LEFT_TURN) 
}) 
```

## 步驟 4

讓 Agent 用 ``||agent:向前移動||`` 向前移動 **5** 格，再用 ``||agent:Agent 轉向||`` **右轉**，接著再用 ``||agent:Agent 移動||`` **向前移動 5 格**。

```javascript
player.onChat("side1", function () { 
    agent.setAssist(PLACE_ON_MOVE, true) 
    agent.move(FORWARD, 4) 
    agent.turn(LEFT_TURN) 
    agent.move(FORWARD, 5) 
    agent.turn(RIGHT_TURN) 
    agent.move(FORWARD, 5) 
    })
```

## 步驟 5

讓 Agent 執行 ``||agent:移動時放置方塊||``，設為 **false**。 

```javascript
player.onChat("side1", function () { 
    agent.setAssist(PLACE_ON_MOVE, true) 
    agent.move(FORWARD, 4) 
    agent.turn(LEFT_TURN) 
    agent.move(FORWARD, 5) 
    agent.turn(RIGHT_TURN) 
    agent.move(FORWARD, 5) 
    agent.setAssist(PLACE_ON_MOVE, false) 
    }) 
```

## 步驟 6

讓 Agent 用 ``||agent:轉向||`` **左轉**，用 ``||agent:移動||`` **向前移動 2 格**，接著再用 ``||agent:轉向||`` **左轉**。

```javascript
player.onChat("side1", function () { 
    agent.setAssist(PLACE_ON_MOVE, true) 
    agent.move(FORWARD, 4) 
    agent.turn(LEFT_TURN) 
    agent.move(FORWARD, 5) 
    agent.turn(RIGHT_TURN) 
    agent.move(FORWARD, 5) 
    agent.setAssist(PLACE_ON_MOVE, false) 
    agent.turn(LEFT_TURN) 
    agent.move(FORWARD, 2) 
    agent.turn(LEFT_TURN) 
})
```

## 步驟 7

建立新的 ``||player:收到聊天指令時||`` 指令，命名為 **side2**。讓 Agent 的 ``||agent:移動時放置方塊||`` 設為 **true**。加入 ``||agent:設定 Agent 物品||`` 指令，將數量設為 **64**。

## 步驟 9
