# 文字列印：間諜任務

## 步驟 1

建立一個 ``||player:收到聊天指令時||`` 指令，命名為 **mix**。在裡面放入名為 **starting_world_position** 的 ``||variables:變數||``，將值設為 ``||player:玩家世界座標||``。

```javascript
player.onChat("mix", function () {
    starting_world_position = player.position()
})
```

## 步驟 2

加入 ``||blocks:印出文字||`` 程式，在位置 **(0,0,0)**，朝**西方**，用 ``||blocks:草地||`` 方塊印出變數 **word1**。

```javascript
player.onChat("mix", function () {
    starting_world_position = player.position()
    blocks.print(
    word1,
    GRASS,
    pos(0, 0, 0),
    WEST
    )
})
```

## 步驟 3

將變數 **starting_world_position** 設為 **(0,0,0)**，將變數 **word1** 設為 **"rail"**。
  
```javascript
Let starting_world_position: Position = null
let word1 = ""
word1 = "rail"
```

## 步驟 4

再建立一個 ``||player:收到聊天指令時||`` 指令，命名為 **mix2**。在這個新的 ``||player:收到聊天指令時||`` **mix2** 指令中，用 ``||blocks:印出文字||`` 在位置 **(0,0,0)** 朝**西方**，以**平滑砂岩**印出變數 **word1**。也要確認變數 **starting_world_position** 已設為 ``||player:玩家世界座標||``。 

```javascript
player.onChat("mix2", function () {
    blocks.print(
    word1,
    SMOOTH_SANDSTONE,
    pos(0, 0, 0),
    WEST
    )
    starting_world_position = player.position()
})
```

## 步驟 5

在 ``||player:收到聊天指令時||`` **mix2** 指令中，用 ``||blocks:印出文字||`` 在位置 **0,0,0** 朝**西方**，以**紫色羊毛**印出新的變數 **word2**。 

```javascript
player.onChat("mix2", function () {
    blocks.print(
    word1,
    SMOOTH_SANDSTONE,
    pos(0, 0, 0),
    WEST
    )
    blocks.print(

    PURPLE_WOOL,
    pos(0, 0, 0),

      starting_world_position = player.position()

```

## 步驟 6

在 ``||player:收到聊天指令時||`` 指令外面，設定一個名為 **word2** 的新變數。

```javascript
let starting_world_position: Position = null
let word2 = ""
let word1 = ""
word1 = "rail"
word2 = "road"
```

## 步驟 7

在 **mix2** 的 ``||player:收到聊天指令時||`` 指令中加入 ``||blocks:印出文字|``，在位置 **(0,0,0)** 朝**西方**，以**青金石**印出 **word1** 和 **word2** 兩個變數。

```javascript
player.onChat("mix2", function () {
    blocks.print(
    word1,
    SMOOTH_SANDSTONE,
    pos(0, 0, 0),
    WEST
    )
    blocks.print(
    word2,
    PURPLE_WOOL,
    pos(0, 0, 0),
    WEST
    )
    blocks.print(
    "" + word1 + word2,
    LAPIS_LAZULI_BLOCK,
    pos(0, 0, 0),
    WEST
    )
    starting_world_position = player.position()
})
```

## 步驟 8

取出 ``||player:玩家行走時||``，設為 **fly**（飛行）。建立名為 **alphabet** 的新變數，將字串「ABCDEFGHIJKLMNOPQ」指定給它。把這個變數拖進 ``||player:玩家飛行時||``。

```javascript
player.onTravelled(FLY, function () {
    alphabet = "ABCDEFGHIJKLMNOPQ"
})
```

## 步驟 9

再加入一個 ``||variables: 變數||``，命名為 **RandomLetter**。取出 ``||math:隨機取數||``，將範圍設為 **0** 到 **12**，再把整個 ``||math:隨機取數||`` 放進 **RandomLetter** 變數中。要印出字母，請在 ``||player:玩家飛行時||`` 中，於 **RandomLetter** 變數下方放入 ``||blocks:印出文字||``。在 ``||blocks:印出文字||`` 中放入取得字元的積木，分別指定 **alphabet** 和 **RandomLetter** 變數。將 ``||blocks:印出文字||`` 其餘參數設為**南瓜**、**(-5, 2, 0)**，方向設為**西方**（x 軸負方向）。


```javascript
player.onTravelled(FLY, function () {
    alphabet = "ABCDEFGHIJKLMNOPQ"
    RandomLetter = Math.randomRange(0, 12)
    blocks.print(
    alphabet.charAt(RandomLetter),
    PUMPKIN,
    pos(-5, 2, 0),
    WEST
    )
})
```

## 步驟 10

設定 **alphabet** 和 **RandomLetter** 變數。為了保持一致，將它們放在其他變數設定的位置。再加入一個 ``||variables: 變數||``，選擇 **alphabet** 變數，放入文字 ``||text:""||`` 積木，將值設為空字串 **“”**。把 **alphabet** 變數拖進 ``||loops: 開始時||``，緊接在 **word2** 變數下方。再加入一個 ``||variables:變數||``，選擇 **RandomLetter** 變數，將值設為 **0**。把 **RandomLetter** 拖進 ``||loops: 開始時||``，緊接在 **alphabet** 變數下方。

```javascript
let RandomLetter = 0
let alphabet = ""
let starting_world_position: Position = null
let word2 = ""
let word1 = ""
word1 = "rail"
word2 = "road"
```
