# 第 1 課：用程式建造公園圍欄

## 步驟 1
將 ``||Player:收到聊天指令時||`` 積木中的 **run** 改為 **park_fence**。

把 ``||Agent:Agent 設定使用的物品欄||`` 積木拖到程式工作區，放進 ``||Player:收到聊天指令時||`` 積木中。

``` blocks
    agent.setSlot(1)
```
``` blocks
})
```

## 步驟 3
把 ``||Agent:Agent 移動 [前方]||`` 積木拖到工作區，放進 ``||Player:收到聊天指令時||`` 程式組中的 ``||Loops:重複 [25] 次||`` 迴圈，距離設為 **1**。

把 ``||Agent:Agent 放置 [前方]||`` 積木拖到工作區，放進 ``||Player:收到聊天指令時||`` 程式組中的 ``||Loops:重複 [25] 次||`` 迴圈，接在 ``||Agent.agent move[forward]||`` 下方，方向從 **前（forward）** 改為 **後（back）**。

### ~ tutorialhint
``` blocks
player.onChat("park_fence", function () {
    agent.setSlot(1)
    for (let index = 0; index < 25; index++) {
        agent.move(FORWARD, 1)
        agent.place(BACK)
    }
})
```

## 步驟 4
把 ``||Agent:Agent 轉向 [左]||`` 積木放在 ``||PLayer:收到聊天指令時||`` 程式組的迴圈後方。依 Agent 下一段路線設定轉向；本例為 **左（left）**。

### ~ tutorialhint
``` blocks
player.onChat("park_fence", function () {
    agent.setSlot(1)
    for (let index = 0; index < 25; index++) {
        agent.move(FORWARD, 1)
        agent.place(BACK)
    }
    agent.turn(LEFT_TURN)
})
```

## 步驟 5
測試程式。把 Agent 放在起始方塊，按 **T** 開啟聊天視窗，輸入 **park_fence**。
