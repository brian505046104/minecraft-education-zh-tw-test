## 活動 1

### 放置方塊

Agent 可以放置 Minecraft 方塊，但需要分成幾個步驟。放置之前，Agent 的物品欄裡必須先有方塊。

第一步，使用 ``||agent:設定 Agent 的方塊或物品||`` 將方塊放進 Agent 的物品欄。

#### ~ tutorialhint

Agent 預設會從物品欄第一格放置方塊，因此使用 ``||agent:設定 Agent 的方塊或物品||``，將方塊放進 Agent 物品欄的第 **1** 格。

### 依方塊名稱搜尋

``||agent:設定 Agent 的方塊或物品||`` 的下拉選單很長，要找到特定的 Minecraft 方塊，可能不太容易。

在下拉選單中搜尋 **redstone**（紅石），就能快速找到並選取 **Block of Redstone**（紅石方塊）。

#### ~ tutorialhint

```blocks
player.onChat("place", function () {
    agent.setItem(REDSTONE_BLOCK, 1, 1)
})
```

### 依序執行敘述

將方塊放進 Agent 物品欄後，第二步是讓 Agent 執行 ``||agent:Agent 放置方塊||``，將方塊放下。

從 ``||agent:AGENT||`` 類別拖出 ``||agent:Agent 放置方塊||`` 積木，接到 ``||agent:設定 Agent 的方塊或物品||`` 下方，再執行名為 **place** 的 ``||player:聊天指令||``。


#### ~ tutorialhint

```blocks
player.onChat("place", function () {
    agent.setItem(REDSTONE_BLOCK, 1, 1)
    agent.place(FORWARD)
})
```

```template
player.onChat("place", function () {
    agent.setItem(GRASS, 1, 1)
})
```

```ghost
player.onChat("run", function () {
    agent.setItem(REDSTONE_BLOCK, 1, 1)
    agent.place(FORWARD)
})
```
