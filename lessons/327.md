# 事件樂趣：JavaScript

## 步驟 1
建立一個事件：當 ``||player:玩家||`` 走路時，在位置 (0,**10**,0) 生成**投射物煙火火箭**。

```javascript
player.onTravelled(WALK, function () {
    mobs.spawn(FIREWORKS_ROCKET, pos(0, 10, 0))
})
```

## 步驟 2
在生成程式外面加上 ``||loops:計次迴圈||`` 迴圈，讓程式執行 **25 次**。

```javascript
player.onTravelled(WALK, function () {
    for (let index = 0; index < 25; index++) {
        mobs.spawn(FIREWORKS_ROCKET, pos(0, 10, 0))
    }
})
```

## 步驟 3
建立一個事件：當**橡木**被 ``||blocks:onBlockBroken||`` 破壞時，在位置 (0,10,0) 生成一隻**雞**。 

```javascript
blocks.onBlockBroken(PLANKS_OAK, function () {
    mobs.spawn(CHICKEN, pos(0, 10, 0))
})
```

## 步驟 4
在生成程式外面加上 ``||loops:計次迴圈||`` 迴圈，讓它重複 **25 次**。 

```javascript
blocks.onBlockBroken(PLANKS_OAK, function () {
    for (let index = 0; index < 25; index++) {
        mobs.spawn(CHICKEN, pos(0, 10, 0))
    }
})
```

## 步驟 5
建立一個事件：當**金蘋果**被 ``||player: 使用物品時||`` 使用時，以 ``||mobs:套用效果||`` 對**所有雞**施加**漂浮**效果，持續時間設為 **10**，高度設為 **5** 格。 

```javascript
player.onItemInteracted(GOLDEN_APPLE, function () {
    mobs.applyEffect(LEVITATION, mobs.entitiesByType(CHICKEN), 10, 5)
})
```

## 步驟 6
按下**執行**按鈕，回到 Minecraft，測試所有事件。 


```javascript
player.onTravelled(WALK, function () {
    for (let index = 0; index < 25; index++) {
        mobs.spawn(FIREWORKS_ROCKET, pos(0, 10, 0))
    }
})

blocks.onBlockBroken(PLANKS_OAK, function () {
    for (let index = 0; index < 25; index++) {
        mobs.spawn(CHICKEN, pos(0, 10, 0))
    }
})
player.onItemInteracted(GOLDEN_APPLE, function () {
    mobs.applyEffect(LEVITATION, mobs.entitiesByType(CHICKEN), 10, 5)
})
```
