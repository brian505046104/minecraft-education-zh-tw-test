# 游過熔岩

## 步驟 1
你的挑戰是用 ``||player:游泳||`` 游過熔岩湖。試著對**最近的玩家** ``||mobs:施加抗火效果||``，施加抗火效果。



```ghost
player.onTravelled(SWIM_LAVA, function () {
    mobs.applyEffect(FIRE_RESISTANCE, mobs.target(NEAREST_PLAYER), 10, 1)
    mobs.clearEffect(mobs.target(NEAREST_PLAYER))
})
```
