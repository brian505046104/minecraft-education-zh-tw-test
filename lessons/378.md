## 步驟 2
接著，加入 ``||agent:Agent 向上移動||`` 指令，再接一個 ``||agent:Agent 破壞前方||``。
你能讓 Agent 挖掉第一直行的 **3** 個石頭方塊嗎？

```blocks
agent.destroy(FORWARD)
agent.move(UP, 1)
agent.destroy(FORWARD)
agent.move(UP, 1)
agent.destroy(FORWARD)
agent.move(UP, 1)
```


## 步驟 3
想把同一個動作做 3 次，難道只能把相同的程式寫 3 遍嗎？一定有更好的方法吧？
答案就是迴圈！
使用 ``||loops:重複執行 3 次||`` 指令，就能把裡面的指令重複執行 3 次。
試著把 ``||agent:Agent 破壞前方||`` 和 ``||agent:Agent 向上移動||`` 放進 ``||loops:重複執行 3 次||`` 裡面吧！

```blocks
for (let index = 0; index < 3; index++) {
    agent.destroy(FORWARD)
    agent.move(UP, 1)
}

```


## 步驟 4
最後，運用目前學到的內容，你能再用一個 ``||loops:重複執行 7 次||``，挖完其餘的礦道，一路前進到盡頭的黃金方塊嗎？


```ghost
    for (let index = 0; index < 7; index++) {
        for (let index = 0; index < 3; index++) {
            agent.destroy(FORWARD)
            agent.move(UP, 1)
        }
        agent.move(DOWN, 3)
        agent.move(FORWARD, 1)
    }
```
