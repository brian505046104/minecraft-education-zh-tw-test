
# 事件真好玩：積木

## 步驟 1
取出 ``||player: 玩家行走時||`` 和 ``||mobs:生成||``，拖到工作區。把 ``||mobs: 投射物||`` 拖進 ``||mobs:生成||`` 的**動物參數**，選擇**煙火火箭**。

```blocks
player.onTravelled(WALK, function () { 
    mobs.spawn(FIREWORKS_ROCKET, pos(0, 0, 0)) 
}) 
```
## 步驟 2

把位置的 (y) 座標設為玩家上方 **10 格**，也就是 (0, **10**, 0)。

```blocks
player.onTravelled(WALK, function () { 
    mobs.spawn(FIREWORKS_ROCKET, pos(0, 10, 0)) 
}) 
```
## 步驟 3
把 ``||loops:重複||`` 拖進 ``||player:玩家行走時||``，設為 **25 次**。``||mobs:生成||`` 要放在 ``||loops:重複||`` 裡面。

```blocks
player.onTravelled(WALK, function () {
    for (let index = 0; index < 25; index++) {
        mobs.spawn(FIREWORKS_ROCKET, pos(0, 10, 0))
    }
})
```

## 步驟 4
把 ``||blocks:被破壞時||`` 拖到工作區，選擇**橡木**方塊。

## 步驟 5
加入 ``||mobs:生成||``，設為**雞**，把位置的 (y) 座標設為玩家上方 **10 格**，也就是 (0, **10**, 0)。

```blocks
blocks.onBlockBroken(PLANKS_OAK, function () { 
    mobs.spawn(CHICKEN, pos(0, 10, 0)) 
}) 
```

## 步驟 6
在 ``||blocks:被破壞時||`` 中加入 ``||loops:重複||``，包住 ``||mobs:生成||``，把 ``||loops:重複||`` 設為 **25 次**。

```blocks
blocks.onBlockBroken(PLANKS_OAK, function () { 
    for (let index = 0; index < 25; index++) { 
        mobs.spawn(CHICKEN, pos(0, 10, 0)) 
    } 
}) 
```

## 步驟 7

把 ``||player:使用物品時||`` 拖到工作區，物品設為**金蘋果**。

## 步驟 8

把 ``||mobs: 套用效果至||`` 拖到工作區，選擇**懸浮**，持續時間設為 **10**，強度設為 **5**。

## 步驟 9

取出 ``||mobs:所有動物||``，設為**雞**，拖進 ``||mobs: 套用效果至||`` 的**對象**欄。再把完成的 ``||mobs:套用效果至||`` 拖進 ``||player: 使用物品時||``。  

```blocks
player.onItemInteracted(GOLDEN_APPLE, function () { 
    mobs.applyEffect(LEVITATION, mobs.entitiesByType(CHICKEN), 10, 5) 
}) 
```
