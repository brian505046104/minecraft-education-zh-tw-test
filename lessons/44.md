# Agent 挖掘通道：積木


## 步驟 1
把 ``||player:收到聊天指令時||`` 重新命名為 **"destroy"**。

```blocks
player.onChat("destroy", function () {
})
```

## 步驟 2
在 ``||player:收到聊天指令時||`` 裡加入 ``||loops:當條件成立時重複||``。取出 ``||agent:偵測||``，拖進 ``||loops:當條件成立時重複||`` 的 **true** 欄位，把 ``||agent:偵測||`` 設為**方塊**與**前方**。 

```blocks
player.onChat("destroy", function () {
    while (agent.detect(AgentDetection.Block, FORWARD)) {
    	
    }
})
```

## 步驟 3
取出 ``||agent:破壞||``，設為**前方**，拖進 ``||loops:當條件成立時重複||``。

```blocks
player.onChat("destroy", function () {
    while (agent.detect(AgentDetection.Block, FORWARD)) {
        agent.destroy(FORWARD)
    }
})
```

## 步驟 4

取出 ``||agent:移動||``，設為**向前** **一格**。把 ``||agent:Agent 移動||`` 拖進 ``||loops:當條件成立時重複||``，放在 ``||agent:破壞||`` 後面。

```blocks
player.onChat("destroy", function () {
    while (agent.detect(AgentDetection.Block, FORWARD)) {
        agent.destroy(FORWARD)
        agent.move(FORWARD, 1)
    }
})
```

## 步驟 5

取出 ``||agent:破壞||``，設為**向上**。把 ``||agent: Agent 破壞||`` 拖進 ``||loops:當條件成立時重複||``，放在 ``||agent:移動||`` 後面。

```blocks
player.onChat("destroy", function () {
    while (agent.detect(AgentDetection.Block, FORWARD)) {
        agent.destroy(FORWARD)
        agent.move(FORWARD, 1)
        agent.destroy(UP)
    }
})
```

## 步驟 6

按下**播放**，回到 Minecraft，按 **t**，試用 **destroy**。 

```blocks
player.onChat("destroy", function () { 
    while (agent.detect(AgentDetection.Block, FORWARD)) { 
        agent.destroy(FORWARD) 
        agent.move(FORWARD, 1) 
        agent.destroy(UP) 
    } 
})
```
