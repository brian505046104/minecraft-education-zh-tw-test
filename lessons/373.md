# 0. 入門介紹

## Agent @unplugged

這是一個 Agent。Agent 是可以透過程式指揮的小機器人，能在 Minecraft 裡完成任務。它可以移動、放置方塊，甚至破壞方塊。

![Agent](https://raw.githubusercontent.com/CausewayDigital/Minecraft-EE-MakeCode/main/tutorials/seymour-island/images/seymour_task_0_agent.jpg)

## 準備開始 @unplugged

一起練習使用你的新 Agent！先寫一段程式，指示它從鑽石方塊移到黃金方塊。
![移動中的 Agent](https://raw.githubusercontent.com/CausewayDigital/Minecraft-EE-MakeCode/main/tutorials/seymour-island/images/seymour_task_0_move.gif)

你可以先按 **esc** 關閉這個視窗，找到 Agent。
記住，按 **C** 就能重新開啟。

## 開始寫程式
把 ``||Agent:Agent 移動||`` 積木拖進 ``||loops:開始時||`` 積木中。
接著，將方向從**前方**改成**左方**。
你可能也需要調整移動的步數……

準備好執行程式後，按下右下角的**執行**按鈕。

```blocks
    agent.move(LEFT, 2)
```
