# 第 2 課：用程式建造動物園步道

## 步驟 1
將 ``||Player:收到聊天指令時||`` 積木中的 **run** 改為 **zoo_path_1**。

選取 ``||Blocks:填滿為||`` 積木，拖進 ``||Player:收到聊天指令時||`` 積木中。

#### ~ tutorialhint
``` blocks
player.onChat("zoo_path_1", function () {
    blocks.fill(
    GRASS,
    pos(0, 0, 0),
    pos(0, 0, 0),
    FillOperation.Replace
    )
})
```

## 步驟 2
使用下拉選單，把材料從 **草地（Grass）** 改成 **礫石（Gravel）**。

#### ~ tutorialhint
``` blocks
player.onChat("zoo_path_1", function () {
    blocks.fill(
    GRAVEL,
    pos(0, 0, 0),
    pos(0, 0, 0),
    FillOperation.Replace
    )
})
```

## 步驟 3
打開左側選單中的 ``||Positions:座標||``。

這個工具箱可以讓你透過 ***位置*** 或 ***座標*** 操作 Minecraft 世界。世界中的每個方塊都有 X、Y、Z 軸座標。

把兩個 ``||Positions:世界座標 [0] [0] [0]||`` 橢圓形積木拖到工作區，取代 ``||Blocks:起點||`` 和 ``||Blocks:終點||`` 裡面的 ``||Positions:[~0] [~0] [~0]||``。

#### ~ tutorialhint
``` blocks
player.onChat("zoo_path_1", function () {
    blocks.fill(
    GRAVEL,
    world(0, 0, 0),
    world(0, 0, 0),
    FillOperation.Replace
    )
})
```

## 步驟 4
把 **步驟 3** 記下的第一組座標，填入 ``||Blocks:起點||`` 裡的 ``||Positions:世界座標 [0] [0] [0]||``。

#### ~ tutorialhint
``` blocks
player.onChat("zoo_path_1", function () {
    blocks.fill(
    GRAVEL,
    world(-40, 69, -575),
    world(0, 0, 0),
    FillOperation.Replace
    )
})
```

## 步驟 5
同樣地，把 **步驟 4** 記下的座標，填入 ``||Blocks:終點||`` 裡的 ``||Positions:世界座標 [0] [0] [0]||``。

#### ~ tutorialhint
``` blocks
player.onChat("zoo_path_1", function () {
    blocks.fill(
    GRAVEL,
    world(-40, 69, -575),
    world(-60, 69, -575),
    FillOperation.Replace
    )
})
```

## 步驟 6
將中間的 **Y** 座標減少 1；本例改成 **68**。  

中間的數字代表高度；原教材以世界底部 **0** 到頂部 **256** 說明。我們要把腳下的 **草地（Grass）** 換成 **灰色礫石（Grey Gravel）**，因此需要降低一格。原先記下的是玩家腿部所在方塊的座標，直接執行會讓道路比地面高一格；降低後才會取代草地。

#### ~ tutorialhint
``` blocks
player.onChat("zoo_path_1", function () {
    blocks.fill(
    GRAVEL,
    world(-40, 68, -575),
    world(-60, 68, -575),
    FillOperation.Replace
    )
})
```
## 步驟 7
現在測試程式。如果設定正確，草地的位置就會出現道路。
