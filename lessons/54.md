# 蝙蝠洞：JavaScript

## 步驟 1
新增 ``||player:當收到聊天指令時||`` 指令，命名為 **cave**。

```javascript
player.onChat("cave", function () {
})
```

## 步驟 2

讓玩家執行 ``||player:說出||``，說出 **"Dig a cave"（挖一個洞穴）**，再將它拖進 ``||player:當收到聊天指令時||`` 指令中。

```javascript
player.onChat("cave", function () {
    player.say("Dig a cave")
})
```

## 步驟 3

將時間設為 **day**（白天）。

```javascript
player.onChat("cave", function () {
    player.say("Dig a cave")
    gameplay.timeSet(gameplay.time(DAY))
})
```

## 步驟 4

讓玩家使用 ``||blocks:填滿||`` 填入 **air**（空氣）方塊，位置設為 **from  = -1.0,-1** 和 **to = 1,2,1**，模式設為 **replace**（取代）。

```javascript
player.onChat("cave", function () {
    player.say("Dig a cave")
    gameplay.timeSet(gameplay.time(DAY))
    blocks.fill(
    AIR,
    pos(-1, 0, -1),
    pos(1, 2, 1),
    FillOperation.Replace
    )
})
```

## 步驟 5

將填滿步驟重複 **50** 次。

```javascript
player.onChat("cave", function () {
    player.say("Dig a cave")
    gameplay.timeSet(gameplay.time(DAY))
    for (let index = 0; index < 50; index++) {
        blocks.fill(
        AIR,
        pos(-1, 0, -1),
        pos(1, 2, 1),
        FillOperation.Replace
        )
    }
})
```

## 步驟 6

設定 ``||variables:新增變數||``，命名為 **bat_cave**，再將這個變數設為 ``||player:玩家世界座標||``。

```javascript
let batcave: Position = null
player.onChat("cave", function () {
    player.say("Dig a cave")
    gameplay.timeSet(gameplay.time(DAY))
    for (let index = 0; index < 50; index++) {
        blocks.fill(
        AIR,
        pos(-1, 0, -1),
        pos(1, 2, 1),
        FillOperation.Replace
        )
    }
    batcave = player.position()
})
```

## 步驟 7

讓玩家執行 ``||player:說出||``，說出「蝙蝠抵達前，你有 10 秒可以離開。」

```javascript
player.say("You have 10 seconds to get out before the bats arrive.")
```

## 步驟 8

使用 ``||loops: 暫停||``，將程式暫停 **10** 秒（10,000 毫秒）。

```javascript
player.say("You have 10 seconds to get out before the bats arrive.")
    loops.pause(10000)
player.on_chat("cave", on_chat)
```

## 步驟 9

暫停結束後，讓玩家說出「小心蝙蝠！」。

```spy
loops.pause(10000)
    player.say("Watch out for bats!")
player.on_chat("cave", on_chat)
```

## 步驟 10

將時間設為 **dusk**（黃昏）。

```javascript
gameplay.timeSet(gameplay.time(DUSK))
```

## 步驟 11

在 **bat_cave** 變數指定的位置，使用 ``||mobs:生成||`` 生成一隻蝙蝠。

```javascript
mobs.spawn(BAT, batcave)
```

## 步驟 12

將生成 **bat**（蝙蝠）的 ``||mobs:生成動物||`` 重複 **200** 次。

```javascript
for (let index = 0; index < 200; index++) {
        mobs.spawn(BAT, batcave)
    }
```

## 步驟 13

回到 Minecraft，在聊天室輸入 **cave**，執行整段程式。


```javascript
let batcave: Position = null
player.onChat("cave", function () {
    player.say("Dig a cave")
    gameplay.timeSet(gameplay.time(DAY))
    for (let index = 0; index < 50; index++) {
        blocks.fill(
        AIR,
        pos(-1, 0, -1),
        pos(1, 2, 1),
        FillOperation.Replace
        )
    }
    batcave = player.position()
    player.say("You have 10 seconds to get out before the bats arrive.")
    loops.pause(10000)
    player.say("Watch out for bats!")
    gameplay.timeSet(gameplay.time(DUSK))
    for (let index = 0; index < 200; index++) {
        mobs.spawn(BAT, batcave)
    }
})
```
