# 搬運魚群


## 步驟 1

```template
//
```

這項任務要將小丑魚和河豚從船上搬到碼頭。首先，來收集魚吧！使用 ``||agent:Agent 向前移動 2 格||`` 指令，讓 Agent 移到收集魚的位置上方。
接著使用 ``||agent:Agent 收集 CLOWNFISH||`` 指令，目前先只收集小丑魚。
將程式放在 ``||on start||`` 區段中，再按下執行按鈕。

```blocks
agent.move(FORWARD, 2)
agent.collect(CLOWNFISH)

```

## 步驟 2
已經收集到一些小丑魚了，接著也收集其他位置的小丑魚。試著把程式放進 ``||loops:重複 3 次迴圈||``，或 Python 的 ``||loops:計次迴圈||`` 中。

```blocks
for (let index = 0; index < 3; index++) {
    agent.move(FORWARD, 2)
    agent.collect(CLOWNFISH)
}

```

## 步驟 3
收集完所有小丑魚後，寫一段程式，讓 Agent 移到碼頭上正確的卸貨位置，再用 ``||agent:Agent 逐一丟出物品||`` 指令，把所有魚放進桶子裡。

```ghost
agent.dropAllItemsIndividually(FORWARD)

```
