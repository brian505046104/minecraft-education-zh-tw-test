# 編寫程式，讓 Agent 走到金色壓力板！

## 步驟 1
選取 ``||player:收到聊天指令時||``，把名稱從 **run** 改為 **1**。選取 ``||agent: Agent 向前移動||``，拖進 ``||player:收到聊天指令時||``。把移動**步數**改為 **3**，讓 Agent 到達金色壓力板。完成後按**播放**編譯程式，再回到 Minecraft，按 **t**，輸入 **1**。

#### ~ tutorialhint 
修改 ``||agent: Agent 移動||`` 裡的數字，就能改變 Agent 的移動步數。也能使用 ``||agent: Agent 轉向||``，讓 Agent 左轉或右轉。
