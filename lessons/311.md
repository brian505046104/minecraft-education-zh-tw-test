# 迴圈小屋：積木

## 步驟 1
取出 ``||player:收到聊天指令時||``，命名為 **teleport**。取出 ``||agent:把 Agent 傳送到玩家||``，拖進 ``||player:收到聊天指令時||``。  

```blocks
player.onChat("tp", function () { 
    agent.teleportToPlayer() 
}) 
```

## 步驟 2
新增 ``||player:收到聊天指令時||``，命名為 **walls**。

```blocks
player.onChat("walls", function () { 
 
}) 
```

## 步驟 3
取出 ``||agent:設定方塊或物品||``，拖進 **walls** 的 ``||player: 收到聊天指令時||``。選擇**相思木材**，數量設為 **64**，物品欄格數設為 **1**。

```blocks
player.onChat("walls", function () { 
    agent.setItem(PLANKS_ACACIA, 64, 1) 
}) 
```

## 步驟 4
取出 ``||loops:重複||`` 迴圈，設為 **3** 次，拖進 **walls** 的 ``||player:收到聊天指令時||``，放在 ``||agent:設定方塊或物品||`` 下方。在 ``||loops:重複||`` 裡加入 ``||agent:Agent 移動||``，設為**向上 1 格**。

```blocks
  player.onChat("walls", function () { 
    agent.setItem(PLANKS_ACACIA, 64, 1) 
    for (let index = 0; index < 3; index++) { 
        agent.move(UP, 1) 
    } 
}) 
```

## 步驟 5
再取出 ``||loops:重複||``，設為 **4** 次，拖進第一個 ``||loops:重複||``，放在第一個 ``||agent:移動||`` 下方。在第二個 ``||loops:重複||`` 裡加入 ``||agent:Agent 右轉||``。

```blocks
player.onChat("walls", function () { 
    agent.setItem(PLANKS_ACACIA, 64, 1) 
    for (let index = 0; index < 3; index++) { 
        agent.move(UP, 1) 
        for (let index = 0; index < 4; index++) { 
            agent.turn(RIGHT_TURN) 
        } 
    } 
}) 
```

## 步驟 6
取出第三個 ``||loops:重複||``，拖進第二個 ``||loops:重複||``，放在 ``||agent: 右轉||`` 上方。把第三個 ``||loops:重複||`` 設為重複 **4** 次。 

## 步驟 7
在最內層的 ``||loops:重複||`` 加入 ``||agent:Agent 放置||``，設為**向下**。再加入 ``||agent:Agent 移動||``，設為**向前 1 格**，拖進最內層 ``||loops:重複||``，放在 ``||agent:放置||`` 向下的積木下方。

```blocks
player.onChat("walls", function () { 
    agent.setItem(PLANKS_ACACIA, 64, 1) 
    for (let index = 0; index < 3; index++) { 
        agent.move(UP, 1) 
        for (let index = 0; index < 4; index++) { 
            for (let index = 0; index < 4; index++) { 
                agent.place(DOWN) 
                agent.move(FORWARD, 1) 
            } 
            agent.turn(RIGHT_TURN) 
        } 
    } 
}) 
```

## 步驟 9
取出 ``||agent:設定方塊或物品||``，設為**紅磚半磚**，數量設為 **64**、格數設為 **1**，拖進 **roof** 的 ``||player:收到聊天指令時||``。再加入 ``||agent:Agent 移動||``，設為向上 **1** 格。

## 步驟 10
把 ``||loops:重複||`` 拖進 **roof** 的 ``||player:收到聊天指令時||``，設為重複 **4** 次。新增 ``||agent:Agent 移動||``，設為**向後 4 格**；再新增 ``||agent:Agent 移動||``，設為**向右 1 格**。  
	
```blocks
player.onChat("roof", function () { 
    agent.setItem(BRICKS_SLAB, 64, 1) 
    agent.move(UP, 1) 
    for (let index = 0; index < 4; index++) { 
        agent.move(BACK, 1) 
        agent.move(RIGHT, 1) 
    } 
}) 
```

## 步驟 11
再取出 ``||loops:重複||``，設為重複 **4** 次。加入 ``||agent:Agent 向下放置||``，以及設為**向前 1 格**的 ``||agent:Agent 移動||``。把這個 ``||loops:重複||`` 拖進上一個重複迴圈，放在 ``||agent:Agent 移動||`` **向後 4 格**上方。

```blocks
player.onChat("roof", function () { 
    agent.setItem(BRICKS_SLAB, 64, 1) 
    agent.move(UP, 1) 
    for (let index = 0; index < 4; index++) { 
        for (let index = 0; index < 4; index++) { 
            agent.place(DOWN) 
            agent.move(FORWARD, 1) 
        } 
        agent.move(BACK, 1) 
        agent.move(RIGHT, 1) 
    } 
}) 
```
