# 超級跳躍：JavaScript

## 步驟 1
新增 ``||player:收到聊天指令時||``，命名為 **“jump”**。

```javascript
player.onChat("jump", function () { 
}) 
```

## 步驟 2

在 ``||player:聊天||`` 中加入程式，用 ``||player:傳送||`` 把玩家傳送到 **(0,100,0)**，也就是比目前位置高 100 格的地方。 

```javascript
player.onChat("jump", function () { 
   player.teleport(pos(0,100,0))  
}) 
```

## 步驟 3

回到 Minecraft，在聊天欄輸入 jump 試試看。  


## 步驟 4

在 “jump” 聊天指令中，加入名為 **num1** 的 ``||variable: 變數||``。   

```javascript
    player.onChat("jump", function (num1) { 
        player.teleport(pos(0,100,0))  
}) 
```

## 步驟 5

把 ``||player:傳送||`` 位置中的 **100** 改為 ``||variable||`` **num1**。 

```javascript
   player.onChat("jump", function (num1) { 
      player.teleport(pos(0,num1,0))  

}) 
```

## 步驟 6

回到 Minecraft，在聊天欄輸入 jump，後面加上任意數字。例如 jump 50 或 jump 100。 


```javascript
player.onChat("jump", function (num1) { 
   player.teleport(pos(0,num1,0))  
}) 
```
