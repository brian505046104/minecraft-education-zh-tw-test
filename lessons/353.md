# Agent 移動：積木

## 步驟 1
建立 ``||player:收到聊天指令時||``，命名為 **“tp”**。

```blocks
player.onChat("tp", function () {
})
```

## 步驟 2

把 ``||agent:把 Agent 傳送到玩家||`` 拖進 **tp** 的 ``||player:收到聊天指令時||``。

```blocks
player.onChat("tp", function () {
    agent.teleportToPlayer()
})
```

## 步驟 3

再取出 ``||player:收到聊天指令時||``，命名為 **“fd”**。

```blocks
player.onChat("fd", function () {
})
```

## 步驟 4

取出 ``||agent:Agent 移動||``，設為**向前 5 格**。 

```blocks
player.onChat("fd", function () {
    agent.move(FORWARD, 5)
})
```

## 步驟 5

再取出 ``||player:收到聊天指令時||``，命名為 **“lt”**。

```blocks
player.onChat("lt", function () {
})
```

## 步驟 6

取出 ``||agent:Agent 轉向||``，設為**左轉**，拖進 ``||player:收到聊天指令時||`` **lt**。

```blocks
player.onChat("lt", function () {
    agent.turn(LEFT_TURN)
})
```

## 步驟 7

再取出 ``||player:收到聊天指令時||``，命名為 **“rt”**。

```blocks
player.onChat("rt", function () {
    agent.turn(RIGHT_TURN)
})
```

## 步驟 8

再取出 ``||agent:Agent 轉向||``，設為**右轉**。把 ``||agent:Agent||`` **右轉**拖進 ``||player:收到聊天指令時||`` **rt**。

```blocks
player.onChat("rt", function () {
    agent.turn(RIGHT_TURN)
})
```


## 步驟 9

按下**播放**，回到 Minecraft，按 **t** 開啟聊天欄。逐一輸入 **tp**、**rt**、**lt**、**fd**，查看結果。


```blocks

    agent.turn(LEFT_TURN)
})

    agent.move(FORWARD, 5)
})

    agent.teleportToPlayer()

    agent.turn(RIGHT_TURN) 

})
```
