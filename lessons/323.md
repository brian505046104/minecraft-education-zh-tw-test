## 步驟 2
建立 ``|||variable:新增變數||``，命名為 **PlayerPosition**。接著把 ``||player:玩家世界座標||`` 拖進設定變數的「**0**」參數位置。

```blocks

player.onChat("position", function () { 
    PlayerPosition = player.position() 
}) 
```

## 步驟 3
再建立一個 ``|||variable: 變數||``，命名為 **from_position**。把 ``||positions:+（加上座標）||`` 積木拖進設定變數的「**0**」參數位置。

將這個 ``||variable:變數||`` 拖到 ``||player:收到聊天指令時||`` 指令的最後面。取出 **PlayerPosition** 的 ``||variable:變數||``，拖進新變數 **from_position** 上方的座標組。將**下方**座標設為(**6**, 0, 0)。

```blocks
let PlayerPosition: Position = null 
let from_position: Position = null 
player.onChat("position", function () { 
    PlayerPosition = player.position() 
    from_position = positions.add( 
    player.position(), 
    pos(6, 0, 0) 
    ) 
}) 
```

## 步驟 4
再建立一個 ``|||variable: 變數||``，命名為 **to_position**。把 ``||positions:+（加上座標）||`` 拖進設定變數的「**0**」參數位置。

將這個 ``||variable:變數||`` 拖到 ``||player:收到聊天指令時||`` 指令的最後面。取出 **PlayerPosition** 的 ``||variable:變數||``，拖進新變數 **to_position** 上方的座標組。將**下方**座標設為(**-6, 13, 0**)。

```blocks
let from_position: Position = null 
let to_position: Position = null 
player.onChat("position", function () { 
    PlayerPosition = player.position() 
    from_position = positions.add( 
    player.position(), 
    pos(6, 0, 0) 
    ) 
    to_position = positions.add( 
    player.position(), 
    pos(6, 13, 0) 
    ) 
}) 
```

## 步驟 6
放入 ``||blocks:填入方塊||`` 積木，設為**玻璃**。把 **from_position** 的 ``||variable:變數||`` 拖進玻璃 ``||blocks:填滿||`` 指令的 **from** 參數位置；再把 **to_position** 的 ``||variable:變數||`` 拖進玻璃 ``||blocks:填滿||`` 指令的 **to** 參數位置。

## 步驟 7
取出 ``||blocks: 方塊被破壞時||`` 指令，設為**玻璃**。放入 ``||blocks:放置||`` 積木，設為**鑽石**。把 ``||positions:隨機選取位置||`` 積木拖進鑽石 ``||blocks:放置||`` 積木的 **at** 參數位置。把 **from_position** 變數拖進鑽石 ``||blocks:放置||`` 積木的 **from** 參數位置，再把 **to_position** 變數拖進鑽石 ``||blocks:放置||`` 積木的 **to** 參數位置。

```blocks
blocks.onBlockBroken(AIR, function () { 
    blocks.place(DIAMOND_BLOCK, randpos( 
    from_position, 
    to_position 
    ))
```

## 步驟 8
複製整組 ``||blocks:方塊被破壞時||`` 積木。將觸發方塊從**玻璃**改為**鑽石**，並將 ``||blocks:放置||`` 放置的**鑽石**改為**橘色羊毛**。
