## 步驟 1
編寫 ``||player: 當收到聊天指令時||`` 指令，命名為 **tp**，讓 Agent 執行 ``||agent:傳送到玩家身邊||``。 

```javascript
player.onChat("tp", function () {
    agent.teleportToPlayer()
})
```

## 步驟 3
使用 ``||agent:Agent||``，將物品設為 **carrots**（胡蘿蔔）、數量 **64**、物品欄第 **1** 格。 

```javascript
player.onChat("farm", function () {
    agent.setItem(CARROTS, 64, 1)
})
```

## 步驟 5
在 ``||loops:for 迴圈||`` 迴圈中，編寫 ``||agent:Agent||``，讓 Agent **向後移動 7 格**。

```javascript
player.onChat("farm", function () { 
    agent.setItem(CARROTS, 64, 1) 
    for (let index = 0; index < 2; index++) { 
        agent.move(BACK, 7) 
    } 
}) 
```

## 步驟 6
在向**後**的 ``||agent:Agent 移動||`` 程式後面，編寫 ``||agent: Agent||``，讓 Agent **向右移動 4 格**。

```javascript
player.onChat("farm", function () { 
    agent.setItem(CARROTS, 64, 1) 
    for (let index = 0; index < 2; index++) { 
        agent.move(BACK, 7) 
        agent.move(RIGHT, 4) 
    } 
}) 
```

## 步驟 7
編寫重複 **7** 次的 ``||loops:for 迴圈||`` 迴圈，放進第一個 ``||loops:for 迴圈||`` 迴圈中，放在 Agent 向後移動的 ``||agent:移動||`` 程式上方。

```javascript
        agent.move(RIGHT, 4) 
    }
```

## 步驟 8
在內層 ``||loops:for 迴圈||`` 迴圈中，編寫 ``||agent:Agent||``，朝 **forward**（前方）耕地。

```javascript
player.onChat("farm", function () { 
    agent.setItem(CARROTS, 64, 1) 
    for (let index = 0; index < 2; index++) { 
        for (let index = 0; index < 7; index++) { 
            agent.till(FORWARD) 
        } 
        agent.move(BACK, 7) 
        agent.move(RIGHT, 4) 
    } 
}) 
```

## 步驟 9
在 ``||agent:Agent 耕地||`` 後面，編寫 ``||agent:Agent||``，讓 Agent **向前移動 1 格**。

```javascript
player.onChat("farm", function () { 
    agent.setItem(CARROTS, 64, 1) 
    for (let index = 0; index < 2; index++) {

        agent.move(BACK, 7) 
        agent.move(RIGHT, 4) 
    } 
}) 
```

## 步驟 10
在向前的 ``||agent:Agent 移動||`` 後面，編寫 ``||agent:Agent||``，讓 Agent 朝下放置。 

```javascript
player.onChat("farm", function () {
```
