## 步驟 13
最後模擬風力變化，加入一段沒有風的時間。目前葉片持續旋轉，供電也快速開關；在適當位置加上暫停，就能呈現無風的效果。

## 步驟 14
回到 ``||Loops:迴圈||`` 選單，取出 ``||Loops:暫停（毫秒）||`` 積木，放在最後一個 ``||Blocks:放置 [空氣]||`` 之後，數字設為 **5000**。  

1000ms 等於遊戲中的一秒。因此設為 5000ms，動畫就會暫停 5 秒，模擬風力發電停止 5 秒。

#### ~ tutorialhint
``` blocks
player.onChat("wind_turbine", function () {
   
})
loops.forever(function () {
    for (let index = 0; index < 20; index++) {
        blocks.place(REDSTONE_BLOCK, world(8, 81, -412))
```
