# 小雞雨：積木程式


## 步驟 1
取出 ``||player:收到聊天指令時||`` 指令，命名為 **"chicken"**。

```blocks
player.onChat("chicken", function (){ 
 
}) 
```

## 步驟 2

取出 ``||mobs:生成動物||``，拖進 ``||player:收到聊天指令時||`` 指令中。將 ``||mobs:生成動物||`` 的動物設為**雞**，座標先保留 (0, 0, 0)，也就是玩家目前在 3D 空間 (x, y, z) 中的位置。

```blocks
player.onChat("chicken", function () { 
    mobs.spawn(CHICKEN, pos(0, 0, 0)) 
}) 
```

## 步驟 3

要將 ``||mobs:生成動物||`` 生成雞的位置，改成玩家頭**上方** 10 格，請把座標中的第二個數值 Y 設為 **10**，成為 (0, 10, 0)。

**注意：**座標中的 **~** 符號，表示這是相對於玩家位置的座標。

```blocks
player.onChat("chicken", function () { 
    mobs.spawn(CHICKEN, pos(0, 10, 0)) 
}) 
```

## 步驟 4

回到 Minecraft，按 **t** 開啟聊天欄，輸入 "chicken"。抬頭看看，一隻雞會從玩家上方 10 格的空中掉下來。

## 步驟 5

一隻雞太孤單了。取出 ``||loops:重複||`` 積木，設為重複 **100** 次。把 ``||mobs:生成動物||`` 拖進 ``||loops:重複||`` **100** 裡，再把重複 100 次的 ``||loops:重複||`` 拖進 **chicken** 的 ``||player:收到聊天指令時||`` 指令中。

回到 Minecraft，按 **t** 開啟聊天欄，輸入 chicken。抬頭看看，100 隻雞會從玩家上方 10 格的空中掉下來。

```blocks
player.onChat("chicken", function () { 
    for (let index = 0; index < 100; index++) { 
        mobs.spawn(CHICKEN, pos(0, 10, 0)) 
    } 
}) 
```
