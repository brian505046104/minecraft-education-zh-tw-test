# 第 2 課：讓 Agent 移動與砍樹

## 步驟 1
要讓 Agent 移動，選取 ``||player:收到聊天指令時||`` 指令，將 **run** 改為 **move**。選取 ``||agent:Agent 移動||`` 指令，拖進 ``||player:收到聊天指令時||`` 指令中。

### ~ tutorialhint
別忘了修改 Agent 要移動的步數。

## 步驟 3
完成的程式要結合 ``||agent:Agent 移動||`` 和 ``||agent:Agent 轉向||`` 指令，讓 Agent 沿著橘色線前進。

## 步驟 4
完成後按下 **播放（Play）** 編譯程式，再回到 Minecraft 世界，按 **T**，輸入 **move**。

## 步驟 5
要讓 Agent 砍樹，新增 ``||player:收到聊天指令時||`` 指令，接著加入 ``||agent:Agent 移動||`` 和 ``||agent:Agent 破壞||`` 指令。想一想 Agent 應該往哪個方向移動。

### ~ tutorialhint
Agent 可以向 **上（up）**、**下（down）**、**前（forward）**、**後（back）**、**左（left）** 或 **右（right）** 移動。

## 步驟 6
別忘了加入 ``||agent:Agent 收集全部||`` 指令，讓 Agent 收集所有木材方塊。
