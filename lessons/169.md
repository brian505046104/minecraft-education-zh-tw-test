# 改變世界！

## 步驟 1
使用 ``||player:玩家行走時||`` 事件，在指定的 ``||positions: 世界座標||`` 座標 **100, 68, 100** 放置方塊。建立 ``||variable||``，命名為 **count**。加入 ``||change count by 1||``，並把 ``||count||`` 變數放進 ``||blocks:放置||``；每次增加 1，就會放置對應方塊 ID 的方塊，例如 1=石頭、2=草地、3=泥土。再用另一個事件，例如 ``||player:玩家落下時||``，重設方塊：把 ``||set count||`` 設為 **0**，重新計數，並在 ``||blocks: 放置||`` 加入 ``||variable:count||``，使用相同世界座標。這樣每次你在世界中跳躍，方塊就會重設。 

### ~ tutorialhint
