## 第一個活動

### 聊天指令

當 Minecraft 聊天視窗收到指定訊息時，``||player:收到聊天指令時||`` 事件積木就會執行裡面的程式。試著在聊天欄輸入 **move**，讓 ``||agent:Agent 向前移動||`` 向前移動一格。
按下綠色執行按鈕，再按 **T**，或點選聊天圖示，開啟 Minecraft 聊天視窗，輸入 **move**。

#### ~ tutorialhint

```blocks
player.onChat("move", function () {
    agent.move(FORWARD, 1)
})
```

```template
player.onChat("move", function () {
    agent.move(FORWARD, 1)
})
```
