## 步驟 2
新增 ``||agent:設定方塊或物品||`` 指令，放進 **walls** 函式中。設定物品為**相思木材**、數量 **64**、物品欄第 **1** 格。

## 步驟 3
取得 ``||loops:重複||`` 迴圈，設定為 **3** 次，拖進 **walls** 的 ``||functions:函式||``，放在 ``||agent:設定方塊或物品||`` 積木下方。在 ``||loops:重複||`` 迴圈內加入 ``||agent:Agent 移動||`` 積木，設定為**向上 1 格**。

```blocks
function walls () {
    agent.setItem(PLANKS_ACACIA, 64, 1)
    for (let index = 0; index < 3; index++) {
        agent.move(UP, 1)
    }
}
```

## 步驟 4
再取得一個 ``||loops:重複||`` 迴圈，設定為 **4** 次，拖進第一個 ``||loops:重複||`` 迴圈，放在第一個 ``||agent:Agent 移動||`` 積木下方。在第二個 ``||loops:重複||`` 迴圈中加入 ``||agent:右轉||``。

```blocks
function walls () {
    agent.setItem(PLANKS_ACACIA, 64, 1) 
    for (let index = 0; index < 3; index++) { 
        agent.move(UP, 1) 
        for (let index = 0; index < 4; index++) { 
            agent.turn(RIGHT_TURN) 
        } 
    } 
}) 
```

## 步驟 5
取得第三個 ``||loops:重複||`` 迴圈，拖進第二個 ``||loops:重複||`` 迴圈，放在 ``||agent: Agent 右轉||`` 積木上方。將第三個 ``||loops:重複||`` 迴圈設定為重複 **4** 次。在最內層的 ``||loops:重複||`` 迴圈中加入 ``||agent:Agent 放置方塊||`` 積木，設為**向下**。再加入 ``||agent:Agent 移動||`` 積木，設為**向前 1 格**，拖進最內層 ``||loops:重複||`` 迴圈，放在向下的 ``||agent:放置||`` 下方。

```blocks
function walls () {
    agent.setItem(PLANKS_ACACIA, 64, 1) 
    for (let index = 0; index < 3; index++) { 
        agent.move(UP, 1) 
        for (let index = 0; index < 4; index++) { 
            for (let index = 0; index < 4; index++) { 
                agent.place(DOWN) 
                agent.move(FORWARD, 1) 
            } 
            agent.turn(RIGHT_TURN) 
        } 
    } 
}) 
```

## 步驟 8
取得 ``||loops:重複||`` 迴圈，拖進 **roof** 的 ``||functions:函式||``，設定為重複 **4** 次。加入 ``||agent:Agent 移動||`` 積木，設定為**向後 4 格**；再加入 ``||agent:Agent 移動||`` 積木，設定為**向右 1 格**。  
	
```blocks

function walls () {
    agent.setItem(PLANKS_ACACIA, 64, 1)
    for (let index = 0; index < 3; index++) {
        agent.move(UP, 1)
        for (let index = 0; index < 4; index++) {
            for (let index = 0; index < 4; index++) {
                agent.place(DOWN)
                agent.move(FORWARD, 1)
            }
            agent.turn(RIGHT_TURN)
        }
    }
}
function roof () {
    agent.setItem(BRICKS_SLAB, 64, 1)
    agent.move(UP, 1)
    for (let index = 0; index < 4; index++) {
        for (let index = 0; index < 4; index++) {
            agent.place(DOWN)
            agent.move(FORWARD, 1)
        }
        agent.move(BACK, 4)
        agent.move(RIGHT, 1)
    }
}
player.onChat("house", function () {
    walls()
    roof()
})
```
