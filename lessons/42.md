# 建造橋樑：Javascript


## 步驟 1
編寫 ``||player:收到聊天指令時||``，命名為 **“build”**。

```javascript
player.onChat("build", function () {
})
```

## 步驟 2
在 ``||player:收到聊天指令時||`` 裡，讓 Agent 使用 ``||agent:設定方塊||``，選擇**橡木材**，數量 **64**，物品欄第 **1** 格。

```javascript
player.onChat("build", function () {
    agent.setItem(PLANKS_OAK, 64, 1)
})
```

## 步驟 3
讓 Agent 用 ``||agent:向前移動||`` 前進 **1** 格。

```javascript
player.onChat("build", function () {
    agent.setItem(PLANKS_OAK, 64, 1)
    agent.move(FORWARD, 1)
})
```

## 步驟 4

在 ``||player:收到聊天指令時||`` 裡編寫 ``||loops:當條件成立時重複||``，先檢查 Agent 的 ``||agent:未偵測到方塊||`` **下方**。

```javascript
player.onChat("build", function () {
    agent.setItem(PLANKS_OAK, 64, 1)
    agent.move(FORWARD, 1)
    while (!(agent.detect(AgentDetection.Block, DOWN))) {
    	
    }
})
```

## 步驟 5

在 ``||loops:當條件成立時重複||`` 裡，讓 ``||agent:Agent 放置||`` 的方向設為**下方**。

```javascript
player.onChat("build", function () {
    agent.setItem(PLANKS_OAK, 64, 1)
    agent.move(FORWARD, 1)
    while (!(agent.detect(AgentDetection.Block, DOWN))) {
        agent.place(DOWN)
    }
})
```

## 步驟 6

在 ``||agent:向下放置||`` 之後，讓 ``||agent:Agent 移動||`` **向前 1 格**，然後結束 ``||loops:當條件成立時重複||``。

```javascript
player.onChat("build", function () {
    agent.setItem(PLANKS_OAK, 64, 1)
    agent.move(FORWARD, 1)
    while (!(agent.detect(AgentDetection.Block, DOWN))) {
        agent.place(DOWN)
        agent.move(FORWARD, 1)
    }
})
```
## 步驟 7
按下**播放**，回到 Minecraft，按 **t**，試用 **build**。

```javascript
player.onChat("build", function () { 
    agent.setItem(PLANKS_OAK, 64, 1) 
    agent.move(FORWARD, 1) 
    while (!(agent.detect(AgentDetection.Block, DOWN))) { 
        agent.place(DOWN) 
        agent.move(FORWARD, 1) 
    } 
}) 
```
