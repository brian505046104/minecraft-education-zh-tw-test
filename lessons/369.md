# 1. 破壞方塊

## 破壞方塊 @unplugged

我們已經學會移動 Agent，船長想請我們修補船身上一處
損壞的地方。   
需要先收集一塊木材，才能進行修補。    
讓 Agent 破壞前方那塊橘色木材。   
![破壞方塊](https://raw.githubusercontent.com/CausewayDigital/Minecraft-EE-MakeCode/main/tutorials/seymour-island/images/seymour_task_0_break.gif)
