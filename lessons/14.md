# 第 1 課：用程式建造動物園入口

## 步驟 1
將 ``||Player:收到聊天指令時||`` 積木中的 **run** 改為 **build_gates**。

把 ``||Agent:Agent 設定使用的物品欄||`` 積木拖到工作區，保留 **1**。接著新增 ``||Agent:Agent 移動 [前方]||`` 積木，方向改為 **上（up）**，距離保留 **1**。


把 ``||Agent:Agent 移動 [前方]||`` 積木加入主程式，方向改為 **右（right）**，距離保留 **1**。
