# Agent 迷宮：積木程式

## 步驟 1
建立一個 ``||player:收到聊天指令時||`` 指令，命名為 **tp**。

```blocks
player.onChat("tp", function () {
})
```

## 步驟 2

取出 ``||agent:把 Agent 傳送到玩家||`` 指令，拖進 ``||player:收到聊天指令時||`` **tp** 指令中。

**注意：**這個指令很重要，能讓 Agent 傳送到你目前的位置。

```blocks
player.onChat("tp", function () {  
     agent.teleportToPlayer()  
})  
```

## 步驟 3

再取出一個 ``||player:收到聊天指令時||`` 指令，命名為 **side1**。

```blocks
player.onChat("side1", function () {
})
```

## 步驟 4

取出 ``||agent:Agent 移動時放置方塊||`` 積木，設為 **true**，放進 ``||player:收到聊天指令時||`` **side1** 指令中。

```blocks
player.onChat("side1", function () {  
    agent.setAssist(PLACE_ON_MOVE, true)  
     
}) 
```

## 步驟 5

取出 ``||agent:Agent 向前移動||``，將步數設為 **4**。把它放進 ``||player:收到聊天指令時||`` **side1** 指令中，接在前面的指令下方。

```blocks
player.onChat("side1", function () {  
    agent.setAssist(PLACE_ON_MOVE, true)  
    agent.move(FORWARD, 4)  
})  
```

## 步驟 6

加入 ``||agent:Agent 轉向||`` 指令，設為 **turn left**（左轉），拖進 ``||player:收到聊天指令時||`` **side1** 指令中。

```blocks
player.onChat("side1", function () {  
    agent.setAssist(PLACE_ON_MOVE, true)  
    agent.move(FORWARD, 4)  
    agent.turn(LEFT_TURN)  
})  
```

## 步驟 7

再加入一個 ``||agent:向前移動||`` 積木，將步數設為 **5**。把它放進 ``||player:收到聊天指令時||`` **side1** 指令中，接在前面的指令下方。

```blocks
player.onChat("side1", function () {  
    agent.setAssist(PLACE_ON_MOVE, true)  
    agent.move(FORWARD, 4)  
    agent.turn(LEFT_TURN)  
    agent.move(FORWARD, 5)  
    })  
```

## 步驟 8

再加入一個 ``||agent:Agent 轉向||`` 積木，設為 **right**（右轉）。把它放進 ``||player:收到聊天指令時||`` **side1** 指令中，接在前面的指令下方。

```blocks
player.onChat("side1", function () {  
    agent.setAssist(PLACE_ON_MOVE, true)  
    agent.move(FORWARD, 4)  
    agent.turn(LEFT_TURN)  
    agent.move(FORWARD, 5)
    agent.turn(RIGHT_TURN)    
    })  
```

## 步驟 9

在現有 ``||agent:Agent 移動||`` **向前 5 步**的指令上按右鍵，選擇**複製**。把複製出的積木拖進 ``||player:收到聊天指令時||`` **side1** 指令中，接在前面的 Agent 指令下方。

**注意：**使用複製功能，可以節省編排積木程式的時間。

```blocks
player.onChat("side1", function () {  
    agent.setAssist(PLACE_ON_MOVE, true)  
    agent.move(FORWARD, 4)  
    agent.turn(LEFT_TURN)  
    agent.move(FORWARD, 5)  
    agent.turn(RIGHT_TURN)  
    agent.move(FORWARD, 5)  
    })  
```

## 步驟 10

複製現有的 ``||agent:移動時放置方塊||`` 積木，再拖進 ``||player:收到聊天指令時||`` **side1** 指令中，接在前面的 Agent 指令下方。

```blocks
player.onChat("side1", function () {  
    agent.setAssist(PLACE_ON_MOVE, true)  
    agent.move(FORWARD, 4)  
    agent.turn(LEFT_TURN)  
    agent.move(FORWARD, 5)  
    agent.turn(RIGHT_TURN)  
    agent.move(FORWARD, 5)  
    agent.setAssist(PLACE_ON_MOVE, false)  
    })  
```

## 步驟 11

複製現有 ``||agent:Agent 轉向||`` **左轉**指令，再拖進 ``||player:收到聊天指令時||`` **side1** 指令中，接在前面的 Agent 指令下方。

## 步驟 12

複製現有 ``||agent:Agent 移動||`` **向前移動**指令，再拖進 ``||player:收到聊天指令時||`` **side1** 指令中，接在前面的 Agent 指令下方。

## 步驟 13

複製現有 ``||agent:Agent 轉向||`` **左轉**指令，再拖進 ``||player:收到聊天指令時||`` **side1** 指令中，接在前面的 Agent 指令下方。

```blocks
player.onChat("side1", function () {  
    agent.setAssist(PLACE_ON_MOVE, true)  
    agent.move(FORWARD, 4)  
    agent.turn(LEFT_TURN)  
    agent.move(FORWARD, 5)  
    agent.turn(RIGHT_TURN)  
    agent.move(FORWARD, 5)  
    agent.setAssist(PLACE_ON_MOVE, false)  
    agent.turn(LEFT_TURN)  
    agent.move(FORWARD, 2)  
    agent.turn(LEFT_TURN)  
})  
```

## 步驟 14

按下**執行**按鈕，回到 Minecraft，在聊天欄輸入 **tp**，接著輸入 **side1**，看看 Agent 如何建造第一面牆。

## 步驟 15

複製整個 ``||player:收到聊天指令時||`` **side1** 指令，再改名為 **side2**。

## 步驟 16

刪除新 ``||player:收到聊天指令時||`` **side2** 指令中最後四個指令。

```blocks
player.onChat("side2", function () {  
    agent.setAssist(PLACE_ON_MOVE, true)  
    })  
```

## 步驟 17

將第一個 ``||agent:Agent 移動||`` 積木設為**向前 7 步**，最後一個 ``||agent:Agent 移動||`` 積木設為**向前 3 步**。

## 步驟 18

將最後一個 ``||agent:Agent 轉向||`` 指令從**左轉**改為**右轉**。

## 步驟 19

    agent.move(FORWARD, 5)  
    agent.turn(RIGHT_TURN)  
    agent.move(FORWARD, 5)  
    agent.setAssist(PLACE_ON_MOVE, false)  
    agent.turn(LEFT_TURN)  
    agent.move(FORWARD, 2)  
    agent.turn(LEFT_TURN)  
})  
player.onChat("side2", function () {  
    agent.setAssist(PLACE_ON_MOVE, true)  
    agent.move(FORWARD, 7)  
    agent.turn(LEFT_TURN)  
    agent.move(FORWARD, 5)
