## 步驟 2

這項任務要一起修復大型電路。
往下看看電路區：整個區域分成 4 區，你負責修復其中 2 區，朋友負責另外 2 區。兩邊的電路會跨過中央線互相連接，紅石訊號會通過中央的紫色方塊。
注意，你只能在**綠色綠寶石**方塊上放置紅石。

## 步驟 3

你可以替每個方塊分別寫檢查指令，但也可以寫一段程式，掃描所有綠寶石方塊，再放上紅石，這樣不是更方便嗎？
先用 ``||agent:Agent 向左／右移動||``，讓 Agent 移到角落，準備開始。

```blocks
agent.move(LEFT, 1)
```

## 步驟 4

接著，檢查下方的方塊是否等於綠寶石。
先加入 ``||logic:如果就執行||``，在裡面放入 ``||logic:0 = 0||`` 積木。
在比較式左側放入 ``||agent: Agent 檢查下方方塊||``，偵測下方的方塊。
再於右側選擇綠寶石方塊，進行比較。

```blocks
    agent.move(LEFT, 1)
    if (agent.inspect(AgentInspection.Block, DOWN) == EMERALD_BLOCK) {

    }
```

## 步驟 5

在這個 if 陳述式中，如果確實偵測到綠寶石，就用 ``||agent:Agent 向下放置||`` 向下放置紅石。
if 陳述式結束後，也要用 ``||agent:Agent 向前移動 1 格||`` 向前移動 1 格。

```blocks
    agent.move(LEFT, 1)
    if (agent.inspect(AgentInspection.Block, DOWN) == EMERALD_BLOCK) {
        agent.place(DOWN)
    }
    agent.move(FORWARD, 1)
```

## 步驟 6

現在，你已經有完成任務所需的基本積木了。為了減少程式量，也試試 ``||loops:重複 X 次||``，它能讓任務變得簡單許多。
