# 超級跳躍：積木

## 步驟 1
把現有的 ``||player:收到聊天指令時||`` 重新命名為 **“jump”**。 

```blocks
player.onChat("jump", function () { 
}) 
```

## 步驟 2

把 ``||player:把玩家傳送到||`` 放進 ``||player:收到聊天指令時||`` **jump**，在 **“y”** 座標輸入 **100**。 

```blocks
player.onChat("jump", function () { 
   player.teleport(pos(0,100,0))  
}) 
```

## 步驟 3

回到 Minecraft，在聊天欄輸入 **jump** 試試看。


## 步驟 4

 按 ``||player:收到聊天指令時||`` jump 裡的 (+)，建立名為 **num1** 的新 ``||variable: 變數||``。 

```blocks
player.onChat("jump", function (num1) {
    player.teleport(pos(0, 100, 0))
})
```

## 步驟 5

取出名為 num1 的新 ``||variable||``，拖進 ``||player:傳送到||`` 的 **y** 座標。 

```blocks
player.onChat("jump", function (num1) {
    player.teleport(pos(0, num1, 0))
})
```

## 步驟 6

回到 Minecraft，在聊天欄輸入 **jump**，後面加上任意數字。例如 jump 50 或 jump 100。 

```blocks
player.onChat("jump", function (num1) {
    player.teleport(pos(0, num1, 0))
})
```
