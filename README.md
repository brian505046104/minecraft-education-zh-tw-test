# 繁中 Minecraft Education 積木教材

227份積木／JavaScript教學與分開封裝的中文擴充套件，保留Agent、原API、原程式邏輯、積木ID與素材。原始來源及現有授權資料見licenses/。

此資料夾供公開測試使用，尚未完成Minecraft宿主驗收。每次發布時，default branch與固定版本tag必須先指向同一commit；教學網址使用官方MakeCode原生GitHub tutorial路線，擴充依賴全部使用同一固定tag。不要把所有extension加入root pxt.json，也不要將不同課程的同名namespace合併。

此處沒有原始世界、本機帳號、私人記憶或檢查工具。LICENSE正文未在現有供應來源中封存，licenses/SOURCE_REFERENCES.json只保留已取得的原來源與授權metadata，不代替原授權文件。
